\begin{eqnarray}
   \hat{y}_i = \beta_0 + \beta_1 x_i \label{eq24_01} \\ 
   y_i = \hat{y}_i + e_i \label{eq24_02} \\
   e_i \sim N(0,\sigma)\label{eq24_03}
\end{eqnarray}

Translation:
- $\hat{y}_i$: Estimated value of the dependent variable for the $i$th observation
- $\beta_0$: Intercept (constant term) in the linear regression model
- $\beta_1$: Slope (regression coefficient) in the linear regression model
- $x_i$: The independent variable for the $i$th observation
- $y_i$: The actual (observed) value of the dependent variable for the $i$th observation
- $e_i$: The error term (also known as the residual) for the $i$th observation, which represents the difference between the actual value and the estimated value of the dependent variable
- $N(0,\sigma)$: The normal distribution with mean of zero and standard deviation of $\sigma$
