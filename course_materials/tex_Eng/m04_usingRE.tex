% 前回はRに計算させたりデータを入力したり，と統計的な処理をいろいろさせてきました。RStudioは総合開発環境として，こうしたRの計算機能に加えて文書作成機能も持っています。ここではRStudioを使った文書作成を解説したいと思います。
Last time, we had R perform various statistical processes, such as calculations and data entry. RStudio, as an integrated development environment, has not only these computational functions of R but also document creation functions. Here, I would like to explain how to create documents using RStudio.

% 表計算ソフトと文書作成ソフトは別々のものですがセットで販売・利用されることが多いものです。これらをまとめてオフィスソフトということがあります。Microsoftが提供するのはWord, Excel, PowerPointなどのOfficeシリーズですし，Appleが提供するのはPages, Numbers, Keynoteなどです。他にもフリーソフトウェアとしてLibreOfficeシリーズがあり，そこではWriter, Calc, Impress Presentationという名称になっていますが，何も文書作成，表計算，プレゼンテーションのアプリです。こうしたものが一般的に提供されているので，表計算ソフトで数値計算し，文書ファイルで報告書を書いて，プレゼンテーションアプリで紙芝居形式の発表をする，というのがよく行われています。これから皆さんもたくさんこうした資料を作ることになると思いますが，作成に当たっては，表計算ソフトで図表を作って，それをコピー＆ペーストして文書ファイルやプレゼンテーションファイルに切り貼りする，という方法を取ることでしょう。これが短い資料であれば問題ないのですが，長い資料や多くのデータになってきたりすると，貼り付ける図を間違えるとか，数字の修正をする前の図版だった(更新されたグラフにアップデートし忘れた)といった問題が生じやすくなります。これを\keytermL{コピペ汚染}{こぴぺおせん}と言ったりします。
Spreadsheet software and document creation software are separate, but they are often sold and used in sets. They are collectively referred to as office software. Microsoft offers the Office series such as Word, Excel, and PowerPoint, while Apple offers Pages, Numbers, and Keynote. There is also the LibreOffice series as free software, with names such as Writer, Calc, and Impress Presentation, which are applications for document creation, spreadsheet, and presentation. Since these are generally available, it is common to calculate numbers with spreadsheet software, write reports with document files, and make slideshow-style presentations with presentation applications. I think you all will be creating many such materials from now on, but when you create them, you will probably create charts with spreadsheet software, copy and paste them, and paste them into document files or presentation files. This is fine for short materials, but for longer materials or a lot of data, problems such as pasting the wrong diagram, or the diagram was before the numbers were corrected (forgot to update to the updated graph) can easily occur. This is sometimes referred to as "copy-paste contamination."


% 文書作成とそこに含まれる図表や数字の計算が，同じ環境で行われればこの問題は無くなります。RStudioはそれを実現してくれる環境です。計算環境はRが持っていますから，それを文書に組み込む仕組みがあれば良いのです。RStudioではRmarkdownという書式を使ってこれに対応します。RmarkdownはMarkdownといわれる文書形式にRを組み込んだRStudio独自のファイル形式です。メニューから\verb|File > New File > R Markdown|とすすむと，最終的にどの出力形式のファイルが必要か聞いてくるところがあります(図\ref{fig::05_08})。ここにあるように，最終的にHTML，PDF，Wordといったファイル形式で出力ができます\footnote{PDF形式に出力するには，TeXという別のシステムがまた必要ですが，これもRStudioからインストールすることができます。}。ここではひとまずHTMLを選びましょう。Titleには文書タイトルを，Authorには作者名を入れますので，ここも適当なタイトルと皆さんの名前を入れてOKを押してください。
This problem will be eliminated if the creation of documents and the calculation of figures and numbers contained therein are carried out in the same environment. RStudio provides this environment. Since the calculation environment is provided by R, all we need is a mechanism to incorporate it into the document. In RStudio, this is handled by using a format called Rmarkdown. Rmarkdown is a unique file format of RStudio that integrates R into a document format called Markdown. If you go to "File > New File > R Markdown" from the menu, you will be asked what final output format you need (Figure \ref{fig::05_08}). As you can see, output is possible in file formats such as HTML, PDF, and Word\footnote{To output in PDF format, you need another system called TeX, but this can also be installed from RStudio}. For now, let's choose HTML. Insert the document title in "Title" and the author's name in "Author". Please enter an appropriate title and your name then click OK.

In the Rmarkdown file, \verb| # | is not a comment out, but indicates the hierarchy of the headings \footnote{If the color of the heading doesn't change (i.e., it's not emphasized), even though you're typing in the same way, then you need to add a space after the \verb|#| mark. R won't recognize it as a symbol without a delimiter!} . \verb| ##| is level 2, \verb|###| is level 3, and the number of \verb|#| indicates the depth of the hierarchy. The lower the hierarchy, the larger the text is displayed \footnote{Writing reports is beyond the scope of this course, so I'll leave the details to other classes. However, the basis of academic writing is to have structured text. Scientific papers and academic documents have a hierarchical structure, such as paragraphs > headings > subheadings. Especially in psychology papers, it is decided that the paragraphs are 'problem', 'method', 'result', 'discussion', and you cannot change it to your own style arbitrarily.}.

Thus, instead of copying and pasting the calculation results into the document, it is OK to just specify the calculation procedure. By doing so, the person who receives this output document can verify what calculations were made and what the results are. And there should be no 'copy and paste pollution' occurring there! I hope you can see that this is a very convenient and innovative method, in the sense that it ensures there are no mistakes when creating a scientific paper by explicitly stating the method.
