\section{Document creation with Rmarkdown}
\label{Rmarkdown}
Last time, we did various statistical processes such as calculating and inputting data in R. In addition to these R computing features, RStudio also has document creation capabilities as an integrated development environment. Here, we would like to explain about document creation using RStudio.

Spreadsheet software and document creation software are separate things but they are often sold and used as a set. These are collectively referred to as office software. Microsoft offers the Office series, which includes Word, Excel, and PowerPoint, while Apple offers Pages, Numbers, and Keynote, among others. There are also free software options such as the LibreOffice series, which includes Writer, Calc, and Impress Presentation - software for document creation, spreadsheet usage, and presentations, respectively. It is common to use these types of software to perform numerical calculations with spreadsheet software, write reports using document files, and present in slideshow format using presentation software. While creating such documents, it is common to make tables and graphs in spreadsheet software and copy and paste them into document or presentation files. This method works fine for shorter documents, but problems such as pasting the wrong figure or using outdated figures due to forgotten updates can arise, especially as documents become longer or deal with more data. This is often referred to as "copy-paste contamination."

If document creation, including the creation of figures and numerical calculations, is done in the same environment, this problem can be eliminated. RStudio provides such an environment. R has a calculation environment, so if there is a mechanism for incorporating it into a document, it would be ideal. RStudio supports this with a format called Rmarkdown. Rmarkdown is a file format unique to RStudio that incorporates R into a document format called Markdown. When you go to \verb|File > New File > R Markdown| from the menu, there is a prompt asking which output file format is needed in the end (Figure \ref{fig::05_08}). As shown here, the output can be in various file formats, such as HTML, PDF, and Word\footnote{To output in PDF format, another system called TeX is also required, but it can be installed from RStudio.}. For now, let us select HTML. Enter an appropriate document title in Title and your name in Author, and then click OK.
