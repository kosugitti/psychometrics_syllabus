\begin{description}
	\item[1st line] Generate 100,000 normal random numbers with mean 0 and standard deviation 1, and save them into X.
	\item[2nd line] The \texttt{length} function returns the length of a vector. Among the elements of object X, extract only those that satisfy the condition \verb|X>0.3 & X<1.0|, and compute the length of those elements.
	\item[3rd line] Divide the number of data that satisfy the condition by 100,000 to obtain the relative frequency. The relative frequency can be interpreted as a probability.
\end{description}
