\begin{enumerate}
	\item A good test item is an item that can be answered correctly by anyone.
	\item A bad test item is an item that maximizes the variance of test-takers' performance.
	\item Psychological variables such as ability and personality are not clearly defined entities, so even apparently unrelated questions can be useful for measurement.
	\item It is reasonable to assume that the greater the variance of test scores, the greater the amount of information that can be obtained from the measurement.
	\item Validity refers to the degree to which a concept of the target subject to be measured can be assumed prior to the measurement.
	\item Classical test theory proves the impossibility of measuring true ability, as there will always be measurement errors.
	\item Classical test theory shows that the variance of a test can be divided into true variance and error variance.
	\item The covariance between the true value and error measured by a test is generally assumed to be positively correlated.
	\item Reliability is expressed as the proportion of true variance to total variance.
	\item Reliability is expressed as 1-(error variance/total variance).
	\item The mean and variance of measurement errors are 0.
\end{enumerate}
