\begin{itemize}
    \item \verb|geom_point| Draws points. Can be used to create scatterplots.
    \item \verb|geom_boxplot| Draws boxplots.
    \item \verb|geom_bar| Draws bar charts.
    \item \verb|geom_line| Draws lines. Used for creating line charts and other types of charts.
    \item \verb|geom_smooth| Draws a smooth line. The type of line drawn can depend on various functions.
\end{itemize}
