\begin{enumerate}
	\item 良いテスト項目とは，誰にでも正答できる項目である。
	\item 悪いテスト項目とは，受験者の分散を最大にする項目である。
	\item 能力や性格といった心理変数は実体が明らかではないので，一見なんの関係もない質問であっても測定に役立つ。
	\item テスト得点の分散が大きければ大きいほど，その測定から得られる情報量は大きいと考えてよい。
	\item 妥当性とは，測定に先立って，測定しようとする対象概念を想定できることの程度を意味する。
	\item 古典的テスト理論は，測定しても必ず誤差の影響が入るため，真の能力は決して測定できないという不可能性を証明したものである
	\item 古典的テスト理論からは，テスト全体の分散を真の分散と誤差の分散に分割できることが導かれる。
	\item テストによって測定したい真の値と誤差の共分散は一般に正の相関をすると考えられる。
	\item 信頼性は，全分散中に占める真の分散の割合で表される。
	\item 信頼性は，1-(誤差分散/全分散）で表される。
	\item 誤差の平均と分散は0である
\end{enumerate}
