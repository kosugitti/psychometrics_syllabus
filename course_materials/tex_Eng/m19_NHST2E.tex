% \chapter{帰無仮説検定の注意点}
\chapter{Cautions for Null Hypothesis Significance Testing}
\label{m19_NHST2}
% さて前回は帰無仮説検定について説明しましたが，いかがだったでしょうか。
So, last time I explained about null hypothesis testing, how was it?
% まず「関係がない」「差がない」といった\keytermL{帰無仮説}{きむかせつ}をおき，本来主張したいことを\keytermL{対立仮説}{たいりつかせつ}とし，帰無仮説の否定をもって対立仮説の採択とする，という\textbf{背理法}のロジックで結論を導き出しますから，少しひねくれた考え方になっていることに注意が必要です。手元に得られたデータが，帰無仮説の下では滅多に生じ得ないことだということでもって，帰無仮説を棄却するということも理解していただいておりますでしょうか。
First, we set up a \keytermL{null hypothesis}{kimukasetsu} such as "there is no relation" or "there is no difference", and what we really want to argue is the \keytermL{alternative hypothesis}{tairitsukasetsu}. We draw conclusions using the logic of \textbf{reduction to absurdity}, which adopts the alternative hypothesis by denying the null hypothesis, so you need to be aware that it is a slightly twisted way of thinking. Do you understand that the data we have at hand often rejects the null hypothesis on the basis that it is something that rarely occurs under the null hypothesis?

% 今回は，この帰無仮説検定を行った結果を，どのように報告し，どのように解釈するのかについての解説を行います。とくに解釈の仕方については注意が必要で，少し触れたように帰無仮説検定は\textbf{誤用・誤解が多い}ことも指摘されています。筆者の考えでは，背理法というひねくれた考え方と，基準となる確率の考え方が不自然であることに根本的な原因があり，初学者には帰無仮説検定は向いてないのではないかとさえ思います。それでもその手軽さから広く浸透した手法ですから，皆さんが先行研究などで触れる過去の論文の中にも間違えた使い方，間違った解釈をしているものが含まれているかもしれません\footnote{プロの研究者(大学教員など)が書いて，プロの研究者が査読して刊行されている学会論文においてさえ，間違った手法や解釈が含まれている可能性があります。一つは時代的なもので，かつて計算機が十分に発達していなかった頃には正しい分析法が適用できず，やむなく代替案・次善の策として別の方法を使わざるを得なかった，という事情です。当時は正しいとされていた分析手法が，のちの研究で問題が指摘され，より改良された正しい方法ができることもあります。いずれにせよ研究をする上では，常により正しい手法を使うように心がけなければなりません。また，正しくない手法と知りながら実践するような態度は厳に慎まなければなりません。}。皆さんが同じ過ちを犯さないように，しっかりと基礎知識を身につけ，安易で誤った答えに飛びつかないようにしてください。
This time, I will explain how to report the results of this null hypothesis testing and how to interpret them. Particularly, care should be taken when interpreting, as it has been pointed out that null hypothesis testing is often misused and misunderstood. In my opinion, the fundamental cause is that the idea of reductio ad absurdum and the idea of a standard probability are unnatural, and I even think that null hypothesis testing may not be suitable for beginners. Nevertheless, it is a widely accepted method due to its simplicity, so there may be papers in past researches that you encounter that use it incorrectly or misinterpret it. Even in academic papers written by professional researchers (such as university faculty members) and reviewed and published by professional researchers, inappropriate methods and interpretations may be included. One reason for this is the era in which these papers were written. In the past, when computers were not sufficiently developed, it was not possible to apply the correct analytical methods, and they had no choice but to use an alternative or a second-best solution. There were also times when the analytical method that was considered correct at that time was pointed out as problematic in later research, and a more improved method was developed. In any case, in doing research, we should always strive to use a more correct method. Also, we must strictly refrain from practicing a method knowingly that it is not correct. Please make sure not to make the same mistakes, acquire a solid foundation of knowledge, and be cautious not to jump to easy and wrong answers.

% まずは帰無仮説検定の結果報告の仕方について，次のセクションで少し解説していきます。
First, I will briefly explain how to report the results of a null hypothesis test in the next section.

% \section{結果の報告の仕方}
\section{How to Report Results}
% 帰無仮説検定は帰無仮説と対立仮説のモデル対決なので，結果は軍配をはっきり示す必要があります。帰無仮説が勝ったのか，対立仮説が勝ったのかを明記するのです。ちなみに仮説が勝った，というのを\keyterm{採択}{さいたく}{accept}，負けたというのを\keyterm{棄却}{ききゃく}{reject}と言うのでした。ですから「帰無仮説を棄却して対立仮説を採択」，あるいは「帰無仮説が棄却できずに採択，対立仮説を棄却」のどちらかになります。
A null hypothesis test is a model showdown between the null hypothesis and the alternative hypothesis, so the result needs to clearly indicate which one prevails. It must be clearly stated whether the null hypothesis won or the alternative hypothesis won. By the way, winning, in the hypothesis, is referred to as "accept" and losing is called "reject". Therefore, it either becomes "reject the null hypothesis and accept the alternative hypothesis", or "unable to reject and accept the null hypothesis, reject the alternative hypothesis".

% また，結果の判定ですから，判定に使った数字＝検定統計量も報告する必要があります。たとえば相関係数の検定の例では，$t$統計量が使われましたので，これを報告します。また，$t$統計量は$t$分布に従い，これはサンプルサイズに依存する自由度によって調整されるものですから，自由度も報告する必要があります。前回の例では，相関係数$r=0.50$がサンプルサイズ20のデータから得られ，統計的に優位であると結論づけられたのでした。この結果は，次のように報告しましょう。
Also, since this is a judgment based on results, you need to report the number used for judgment, i.e., the test statistic. In the example of a correlation coefficient test, the $t$ statistic was used, so you would report this. Also, the $t$ statistic follows a $t$ distribution, which is adjusted by degrees of freedom that depend on the sample size, so you also need to report the degrees of freedom. In the previous example, the correlation coefficient $r=0.50$ was obtained from data with a sample size of 20, and it was concluded to be statistically significant. This result should be reported as follows.
\input{m19_NHST2_escape_01}
% 書き方のポイントとしては，統計量を書くこと，そしてその時の統計量はイタリック(斜体)であること\footnote{字体を整えるのは，心理学だけでなく論文の書き方として一般的です。統計量や本のタイトルなどはイタリックであることが決まっています。誰が決めているかって? America Psychological AssociationのPublication Manualにそう定められていますし，日本の心理学会も基本的にこれに準じた出版作法を定めているのです。}，その統計量の実現値が得られる確率($p$値)を記載すること，です。
The key points in writing are to write statistical values and make sure that these values are italicized\footnote{Adjusting the font is a common practice not only in psychology but also in writing papers in general. It has been established that statistical values and book titles are italicized. Who decided this? It has been stipulated by the Publication Manual of the American Psychological Association, and the Japanese Psychological Association also basically stipulates publishing methods in accordance with this.}, and to mention the probability ($p$ value) of obtaining the realization values of those statistics.

% $p$値は上の例のように確率そのものを描くのが基本ですが，昔は判定基準を使って$p<0.05$とか$p<0.01$と書いていました。これは手計算で検定をしていた頃の名残で，統計環境Rなどがなかったものですから確率計算が直接できませんでした。ではどうしていたか，というと代表的な確率分布の数字が載っている数表\footnote{昔は確率分布の数字の一覧が載っている本がありました。確率のテキストには付録として，数表の一部が載っているものもあります。}を使ってチェックするしかなかったので，細かい数字まで計算できなかったのです\footnote{たとえばt分布は自由度によって変わりますが，自由度$1,2,3\cdots$と1つずつ書いてあったのでは，付録のページ数がいくつあっても足りません。そこで$1,2,3...10,15,30,50$のように，後半の方は「だいたいこれぐらい」という大雑把な幅でしか載っていませんでした。こんな時，じゃあ自由度18ならどうしたらいいんだ，と思うかもしれませんが，その時は手元のデータに最も近く，より厳しい自由度15のところを見て代替する，というやりかたでした。ですから具体的な$p$値は書けなかったのです。}。今ではそういう問題がないので，そのまま$p$値を書きましょう。
The $p$ value essentially depicts probability as seen in the above example, however, historically it would be written as $p<0.05$ or $p<0.01$ due to a standard criterion. This is a remnant from when tests were manually calculated, as computational tools for statistical environments such as R were not available, so it wasn't possible to compute probability directly. So, what did they do? Use reference tables with typical probability distribution values \footnote{In the past, there were books with lists of probability distribution values. Some probability textbooks included a part of these lists as an appendix.}. It was impossible to calculate precise numbers due to the limitations of these tables \footnote{For instance, the t-distribution changes depending on the degrees of freedom, but it wasn't possible to list each degree of freedom such as $1, 2, 3 \cdots$ because it would take up too many pages in the appendix. So, the list would skip to numbers like $1, 2, 3... 10, 15, 30, 50$, etc. For the latter part of the list, the numbers were included with an approximation of 'roughly this much'. In such a situation, one might wonder what to do if they have a degree of freedom of 18; in that case, they would check the nearest stricter degree of freedom in their data, 15, as a substitute. Hence, they couldn't write specific $p$ values.}. Nowadays, we don't have such issues, so we should just write the $p$ value directly.

% \section{統計的に有意とは}
\section{What is statistically significant}
\label{statistical_significant}
% さてここまで，(ひとつの)平均値の検定や，相関係数の検定を行なってきました。
So far, we have been conducting tests on (one) average value and correlation coefficient.
% 想定された平均値と大きく違っている/いない，とか，母集団での相関関係がある/ない，という事例でしたが，最終的には帰無仮説を棄却する/採択する，という話になるのでした。
This was a case where it greatly deviates from/did not deviate from the expected average value, there is/is not a correlation in the population. Ultimately, it was a discussion about whether to reject/adopt the null hypothesis.

% この時，帰無仮説が棄却できると「統計的に有意statistically significant」というのでした。統計的に意味が有る，というわけです。ただし気をつけて欲しいのは，統計的に有意とはどういうことか，です。
At this point, being able to reject the null hypothesis means it is "statistically significant". It means that it has statistical meaning. However, what I want you to be careful about is what does statistically significant mean.

% 相関係数の検定の時のことを思い出しましょう。帰無仮説は$\rho=0$というものでした。これが棄却されたので，「統計的に有意な相関係数だ」と結論づけたわけですが，より正しくは「母相関が0であるとはいえない」ということですよね。関係がないとは言えない$\to$関係がある，というこの$\to$の部分は，厳密に言えば少し飛躍があることになります\footnote{「あなたのことが嫌いではない」といわれても好きだとは言われてないわけで。}。
Let's recall the test of the correlation coefficient. The null hypothesis was $\rho=0$. This was rejected, so we concluded that it was a "statistically significant correlation coefficient", but more precisely, it means that "it cannot be said that the population correlation is 0". The link between "cannot be said to be unrelated" $\to$ "related", in this $\to$ part, strictly speaking, involves a slight leap of judgment \footnote{Just because someone says they don't dislike you, doesn't mean they like you.}.

% この帰無仮説検定を考えた人は，R.A.フィッシャーという人なのですが，この人は帰無仮説が棄却されたら「なにかおかしなことが現実に起こっているのだから，実験手続きを見直したほうがいい」というチェックのために使うことが想定していました。これをE.ピアソンとJ.ネイマンという人が「帰無仮説の棄却＝対立仮説の採択，とすれば良い」という判断基準と合わせて使う方法への応用したのです。心理学ではその流れを受けて帰無仮説検定を利用してきました。そういう意味で，本来の創始者の意図とは違った，より実践的な意味のある(言い換えれば実用上の責任を負わなければならない)使い方をしているのです。
The person who came up with this null hypothesis test is a man named R.A. Fisher. He assumed that if the null hypothesis is rejected, something strange is happening in reality, so it would be better to review the experimental procedure. This was applied by E. Pearson and J. Neyman who said, "if the null hypothesis is rejected, then the alternative hypothesis should be accepted," which is a judgement criterion. Psychology has been using the null hypothesis test following this trend. In this sense, it is used in a more practical sense, different from the original intent of its founder (in other words, there is a need to take practical responsibility).

% また既に述べたように，実際の相関係数の大きさや，平均値の差についての情報がかき消された表現になっていることにも注意が必要です。最終的な判断は$p$値だけを見るのですが，この数字だけみても相関係数の大きさや，平均値の差がどれぐらいあったのかはわかりません。有意になったという結果だけをみて，関係があったのか，そうかー，と考察を巡らせても，実は標本相関係数が$r=0.1$だったということもありえるのです\footnote{実際に，サンプルサイズが271人を超えると，標本相関係数が$0.1$でも5\%水準で有意になります。}。これで「統計的に有意だ！無相関とは言えない！」と言っても，標本相関係数が0.1なのですから，「(相関)関係がある」という結果をもとに議論するとおかしなことになってしまいます。
As already mentioned, note that this is an expression where information about the actual correlation coefficient and differences in means have been erased. The final judgement is made by looking at the $p$ value alone, but just looking at this number does not tell you how large the correlation coefficient was or how much the difference in means was. Even if you just look at the result that it was significant and think, "So there was a relationship" and reflect on it, it could actually be that the sample correlation coefficient was $r=0.1$\footnote{In fact, if the sample size exceeds 271 people, the sample correlation coefficient will be significant at the 5\% level even if it's $0.1$.}. Even if you say, "It's statistically significant! We can't say it's uncorrelated!" with a sample correlation coefficient of 0.1, discussing on the result of "there is a (correlation) relationship" will lead to absurdities.

% ところが実際，このような表面上の使われ方に引っ張られてしまうことはよくあります。とくに研究をしていると，努力したのに関係がなかったとは\underline{言いたくない}という気持ちが働いてしまいます。そこで，有意になったんだから意味はあるよね，と考えて無理やり二変数間の関係を考察してしまう，ということになってしまいます。これではせっかくデータを取ったのに，正しく考えられたことになりません。
However, it is often the case that we get pulled along by such superficial usage. Especially when conducting research, there is a feeling that you don't want to say "it was irrelevant despite my efforts." Therefore, there's a tendency to force an interpretation of a relationship between two variables, thinking "it was significant, so there must be a meaning." This results in not being able to think correctly, despite having collected the data.

% 一般にサンプルサイズが大きいと，$p$値は小さくできますから，帰無仮説は棄却しやすくなります。図\ref{fig::18_02}には，横軸にサンプルサイズ，縦軸に$p$値をとり，標本相関係数が$r=0.5,0.3,0.1$のときにどうなるかをプロットしました。5\%を有意水準(点線)としていますが，サンプルサイズが大きくなるにつれて$p$値は小さくなって行きます。
Generally, the larger the sample size, the smaller the $p$ value can be, making it easier to reject the null hypothesis. In Figure \ref{fig::18_02}, we plotted the sample sizes on the x-axis and the $p$ values on the y-axis, and showed what happens when the sample correlation coefficient is $r=0.5,0.3,0.1$. We use 5% as the significance level (dotted line), and as the sample size increases, the $p$ value decreases.

\input{m19_NHST2_escape_02}

% この下がり方はどこからスタートするかにかかわらず同じ形ですから，判定はサンプルサイズが増えさえすればいずれ有意になるのです。これがまた，研究の実践ではおかしな風潮を呼んでしまいます。つまり，\underline{有意にしたければ}サンプルサイズをたくさん取る＝頑張れば良いのです。
This decline is the same regardless of where you start, so the decision will become significant as long as the sample size increases. This also leads to a strange trend in research practice. In other words, if you want to make it significant, you just need to take a lot of sample sizes = it's good if you work hard.

% しかしながら，科学的に正しいかどうかを考えるべきシーンで，「頑張れば有意になる」といった``努力''に依存するのはおかしいことだと思いませんか。頑張った$\to$有意になった$\to$著者の主張が正しい，というのは，論理的ではありません。結果を自分の都合の良いように変えることは，正しい努力ではないはずです。
However, don't you think it's strange to depend on "effort" like "If you try hard, it will be significant" in scenes where you should consider whether it's scientifically correct or not? The logic that works hard -> becomes significant -> the author's claim is correct, is not logically. Changing the results to your advantage is not supposed to be the right effort.

% 帰無仮説検定は，標本から母集団のことを「判定」できる優れた技術ですが，表現とその解釈に気をつけないと，科学を間違った方向に導きかねないことに注意が必要です。残念ながら，これまでの心理学の歴史の中でもこのような間違った努力がなされてきた事実があります。これらは\keyterm{問題のある研究実践}{もんだいのあるけんきゅうじっせん}{Questionable Research Practices}，すなわち\keytermL{QRPs}{QRPs}と言われています。たとえば「有意な結果にするために」サンプルサイズを増やすとか，「有意な結果になるまで」検定を繰り返す，といったことこれに当たります。そうした研究実践が実際に行われている現場も少なくないようです。しかしそんなことをしていると，必然的に科学の議論が「正しくない結果(の解釈)」に基づきますから，後続の研究が土台から崩れ，長年の努力が無駄になってしまいます。データの捏造や，他人の書いた論文を盗む剽窃は明らかに悪意のある行為ですが，「頑張ってデータを増やす」というのは一見真面目で誠実な研究態度に思えてしまうので，ちょっとタチが悪い問題です。努力が人を誤らせるのですから。皆さんも騙されたり間違った道に進んでしまわないよう，十分に注意して研究を進めてください。
Hypothesis null testing is a great technique that allows us to make "judgments" about the population from the sample, but care must be taken in the expression and interpretation of the data, as it may otherwise lead science in the wrong direction. Unfortunately, there have been cases in the history of psychology where such mistakes have been made. These are referred to as "Questionable Research Practices" or QRPs for short. For example, increasing the sample size "to achieve significant results", or repeatedly testing "until significant results are obtained", fall into this category. It seems that there are not a few sites where such research practices are actually being carried out. However, if you do such a thing, the scientific discussion will inevitably be based on "incorrect results (interpretations)", so the subsequent research will collapse from the foundation, and many years of effort will be wasted. Data fabrication and plagiarism, which involves stealing papers written by others, are clearly malicious acts, but "working hard to increase data" can seem like a diligent and sincere research attitude at first glance, which makes it a slightly tricky problem. It's about effort leading people astray. Please be careful not to be deceived or go down the wrong path in your research.

% \section{検定における2種類の間違い}
\section{Two Types of Errors in Hypothesis Testing}
% \subsection{$p$値とは何か}
\subsection{What is a p-value?}
\label{TypeI_II_Error}
% ところで，帰無仮説検定は「推定」の応用である「判断」だということでした。判断が確率的に行われるのですが，人間は確率的な考え方が得意ではありませんから，うっかり間違って理解してしまうことも少なくありません。正しい判断，間違った判断というのはどういうときに起こるのかを考えてみましょう。
By the way, the null hypothesis testing was said to be a judgment, which is an application of estimation. The judgment is made probabilistically, but humans are not good at thinking probabilistically, so we often mistakenly understand it. Let's consider when the correct judgment and the wrong judgment occur.

% まず先ほどから$p$値と呼ばれる数字を使って説明してきましたが，改めてこの$p$値は何を表している数字でしょうか？ 次の選択肢の中から考えてみてください。
We have been using a number called the "p" value, but what does this "p" value represent? Please think about it from the following choices.

\input{m19_NHST2_escape_03}

% 実は正解は，上のどれでもない，です。意地の悪い選択肢でごめん。
Actually, none of the above are correct. Sorry for the tricky options.

% 上の2つの選択肢，「帰無仮説の生じる確率」「帰無仮説の正しさを表している数字」はよくある勘違いです。
The two options above, "The probability of the null hypothesis occurring" and "The number representing the correctness of the null hypothesis" are common misconceptions.
% 仮説検定は「帰無仮説の下で・・・」という前提から始まります。無相関検定のときに，母相関が0の世界から標本をピックアップする例をお話ししましたね。母相関の世界を前提として・・・という話なので，帰無仮説の生じる確率は100\%，帰無仮説の正しさも100\%です(だって仮定したんだから！)。
Hypothesis testing begins with the premise "under the null hypothesis...". We talked about the example of picking up a sample from a world where the population correlation is 0 during the test of no correlation. It's a story assuming the world of population correlation, so the chance of the null hypothesis occurring is 100%, and the correctness of the null hypothesis is also 100% (because we assumed it!).

% 有意の程度の大きさを表す数字でもありません。確かに差が大きいとか，帰無仮説の世界から大きく離れているというようなことがあれば，検定統計量の実現値は大きくなり，$p$値は小さくなります。が，$p$値が示しているのは\underline{(帰無仮説の下での)検定統計量の出現確率}に過ぎません。いわば帰無仮説という仮想空間の中での数字であって，現実の統計量について何か示す数字ではないのです。
The number doesn't necessarily indicate the magnitude of significance. Surely if the difference is large, or we are far from the world of null hypotheses, the realized value of the test statistics will be large, and the $p$ value will be small. However, the $p$ value only shows the \underline{appearance probability of test statistics under the null hypothesis}. It is a number in a hypothetical space called the null hypothesis, and it does not indicate anything about the real statistic.

% 検定の強さを表す数字，でもありません。$p$値が小さくなればなるほど，確かにレア度は増しているのですが，それは帰無仮説という仮想空間の中でのレア度であって，帰無仮説が対立仮説をどれほど打ち負かしたか，という情報を持っているわけではありません。ですから，$p$値が小さければ小さいほどすごい，などと思ってしまうと本質を見誤ります。
The number which indicates the strength of the verification is not just a number. As the $p$ value becomes smaller, the rarity certainly increases, but it's the rarity within the hypothetical space known as the null hypothesis, and it doesn't indicate how much the null hypothesis has beaten the alternative hypothesis. Therefore, thinking that the smaller the p value, the more amazing it is, may lead you to misunderstand its essence.

% では検定の正しさや間違いについて，どのように考えれば良いのでしょうか。実はこれも，確率的表現の難しさがあるのです。
So, how should we think about the correctness or mistakes of the test? In fact, this is also a difficulty of probabilistic expression.
% 帰無仮説検定最後のステップでは「最初に定めた仮説が間違っているか正しいかを判断する」というのがありました。この判断の間違い方にも，2種類あるのです。つまり，「帰無仮説が正しいのに棄却してしまう」という間違い方と，「帰無仮説が正しくないのに採択してしまう」という間違い方です。
In the final step of the null hypothesis test, there was a "determining whether the hypothesis we initially set is correct or incorrect". There are two ways to make this judgement wrong. That is, the mistake of "rejecting the null hypothesis even though it is correct" and the mistake of "adopting the null hypothesis even though it is not correct".

% 図\ref{fig::18_03}に，間違い方の組み合わせを書いてみました。帰無仮説が正しいときに帰無仮説を採択する，帰無仮説が正しくないので帰無仮説を棄却する。これができれば正しい決定ですが，「帰無仮説が正しいのに帰無仮説を棄却する」のも「帰無仮説が正しくないのに帰無仮説を採択する」のも間違いです。
Figure \ref{fig::18_03} shows combinations of ways to make mistakes. Accepting the null hypothesis when it is correct, and rejecting the null hypothesis when it is not correct, are the correct decisions. However, "rejecting the null hypothesis even though it is correct" and "accepting the null hypothesis even though it is not correct" are both mistakes.

% 帰無仮説は差がないとか効果がないといったからっぽ(Null)な結論です。ここでは仮に，開発された新薬に治療効果があるかどうかを考えている，というシーンを想像してみてください。帰無仮説はこの新薬に効果がないときです。ロクな効果がないときに，帰無仮説を棄却する＝対立仮説を採択する＝効果があると言ってしまうのは，怖いことですね(患者さんに副作用など悪影響があるかも！)。このような功を焦って誤った判断をしてしまう危険な間違いを，\keyterm{タイプ1エラー}{たいぷ1えらー}{Type I Error}とよび，その確率を$\alpha$で表します。実は，5\%水準で判断するというのは，この$\alpha$の確率を0.05にしたことになります。慣例では$\alpha=0.05$となっていますが，別に1\%でも10\%でも，自由に決定して構いません。どの程度の水準にするかは，この間違いを犯した時の重要さを参照しながら決めるべきことです。
The null hypothesis is an empty(null) conclusion that there is no difference or effect. Imagine, for instance, a situation where we are examining whether a newly-developed drug has a therapeutic effect. The null hypothesis is that this new drug has no effect. Rejecting the null hypothesis when it has no significant effect, adopting the alternative hypothesis, and stating that there is an effect, is a scary thing, isn't it? (It might have negative effects, such as side effects on the patients!). Such a dangerous mistake of making a hasty judgment is called a Type I Error, and its probability is represented by $\alpha$. In fact, deciding at the 5\% level means that the probability of $\alpha$ has been set to 0.05. Conventionally, $\alpha=0.05$, but you can freely decide whether it's 1\% or 10\%. How much level to set depends on the importance of making this mistake.

% 一方，効果があるのに（帰無仮説が間違ってるのに)，帰無仮説を採択するのは，せっかくの効果を見抜けなかった残念なケースです。これも困った結果ではありますが，少なくとも患者に迷惑がかかるようなことはありませんよね。なので，こちらについてはひとまず間違っても実際的な問題は生じないでしょう。こちらのケースは\keyterm{タイプ2エラー}{たいぷ2えらー}{Type II Error}と呼び，確率は$\beta$で表すのが一般的です。ただ，この$\beta$は帰無仮説が間違っている，つまりNull「でない」状態が，どう「である」のかわからないので，大きさを見積もることはできません。せめて，効果があるときはちゃんとあるって知りたいよね，と思いを馳せるだけです。この図\ref{fig::18_03}にある表は，列ごとに世界線が分かれていますから，右列の「帰無仮説が間違っている世界」で「帰無仮説を棄却してしまう確率」が$\beta$であれば，ちゃんと効果を見つけ出せる確率は$1-\beta$です。この$1-\beta$を\keyterm{検定力}{けんていりょく}{power}といい，検定力のある分析ができているかどうかをちゃんとチェックしておくのは，研究の手続き上重要なことです。
On the other hand, accepting the null hypothesis even when there is an effect (i.e., the null hypothesis is wrong) is a regrettable case where the effect was missed. Though this is also an undesirable result, at least it will not cause any trouble for patients. Therefore, even if we are wrong about this, it may not cause any practical problems. This case is called a Type II Error, and it is generally denoted by the probability $\beta$. However, this $\beta$ cannot be estimated because we do not know what exactly the "not null" situation is. We just hope to know that there is an effect when there is one. In Figure~\ref{fig::18_03}, the worldlines are divided by columns, so in the right column where "the null hypothesis is wrong", if the probability of "rejecting the null hypothesis" is $\beta$, then the probability of finding the effect is $1-\beta$. This $1-\beta$ is called the "power" of the test, and it is important to check whether the analysis has the power in terms of research procedures.

% 先ほど，5\%水準という\keytermL{有意水準}{ゆういすいじゅん}は$\alpha$を設定したことと同義だという話をしました。つまり効果がないのに効果があると言ってしまう，うっかりミスを防いでおこうという方針で判断基準を設計しておきましょうということです。
Earlier, we discussed that the 5% level is synonymous with setting α. In other words, it's about designing a judgment criterion as a policy to prevent careless mistakes, like claiming there's an effect when there isn't.

The probability of both bottles being safe is $0.95 \times 0.95 = 0.9025$. In other words, the probability that at least one of the bottles is compromised is $1-0.9025=0.0975$, surprisingly almost 10\%.

In other words, if you bring ten together, you can see that the risk that was 5% per piece has jumped to 40%.

Well, suppose a diligent researcher is studying a certain phenomenon from various angles, repeatedly conducting statistical tests to draw a conclusion. Because the researcher is very diligent and cautious, they design ten types of experiments in one study, conduct null hypothesis tests at the 5% level ten times each, and carefully repeat their judgment until they obtain a significant effect each time. In fact, it doesn't happen that way. Like the story about wine I mentioned earlier. In other words, if you perform a test 10 times in one study, the possibility of becoming significant by chance (i.e., you judge that there is a difference even when there is none) swells to 40%.
% つまり，一連の研究で5\%の危険率を維持しようとするなら，たとえば10回の検定が含まれるのであれば，それぞれの有意水準はせめて0.5\%にしておかなければなりません。さもないと，うっかりミスの確率がインフレしてしまうのです。

% これも悲しいかな，努力が裏目に出てしまう可能性ですね。一見，1つの論文で複数回の実験や検定を行なっているのは，慎重で真面目であり，有意な結果が出ればそれは十分強い証拠だ，と考えてしまいます。しかしこれはあくまでも0/1の判断であり，しかも確率的な判断ですから，間違いの評価の仕方も確率の理論に沿って丁寧に考えねばなりません！
Sadly, there is a possibility that the effort may backfire. However, this is ultimately a 0/1 judgment, and it's a probabilistic judgment, so the evaluation of the mistakes also needs to be carefully considered according to the theory of probability!

% 実際ひとつの論文の中に複数回の検定が行われていることは，少なくありません。しかしその中で，$\alpha$水準の全体的な調整がなされていることはあまり見かけません。そう，多くの研究者は気づいていながら間違った研究実践をしているのです。「みんな間違っていてみんないい」とはならないのでして，こうした状況は一刻も早く修正する必要がありますが，なぜかなかなか浸透しないところでもあります。本来は，1つの論文全体で調整をかけるべきなのですが・・・。
Indeed, it is not uncommon for a single paper to conduct multiple tests. However, global adjustments at the α level are rarely observed in these cases. Yes, many researchers are conducting flawed research practices, aware of their mistakes. In order not to be swayed by such errors, rather than making a 1-bit judgement of "there is/isn't a difference", it becomes necessary to carefully assess how much of a difference was seen and the magnitude of its effect.

\section{Effect Size and Sample Design}
% 検定力のチェックは，分析が終わった後に事後的にすることもできますし，事前にすることもできます。事前に，というのは，みたい効果がどの程度あるのかを考え，その効果をきちんと検出するにはサンプルサイズをどれぐらいにすれば良いのかを考えること，でもあります。このサンプルサイズを考えることを，\keyterm{例数設計}{れいすうせっけい}{sample size design}といいます。
You can check the power of the test after the analysis is over or in advance. To do this beforehand, you need to think about to what extent the desired effect exists and how much of a sample size is needed to properly detect that effect. This consideration of sample size is referred to as "sample size design".

% 帰無仮説検定において，例数設計はとても大事なことです。既に述べたように，サンプルサイズが大きくなると有意だという判断はしやすくなります。これは$p$値で判断する以上仕方のないことですが，だからと言ってそれを逆手にとって，事実よりも主張をするためにサンプルをたくさんとるのは，帰無仮説検定のハッキングのようなものです\footnote{実際これを\keytermL{p-hacking}{p-hacking}と呼ばれるよくない研究実践の典型例です。}。ですので，検定をするときはまず「どの程度の効果が見込まれ，これを検証するためには何人ぐらいのサンプルをとらなければならない」と宣言してから，検定して判断するという手続きが必要です。この宣言をせずに検定をすると，「有意にするためにサンプルサイズを変えたのではないか」と批判されてしまうかもしれません。学部の授業や卒論で行う実験で，例数設計をしたりサンプルサイズの宣言をするようなことはないかもしれませんが，学術業界では事前に学会にこの宣言を伝えてから研究に取り掛かる，事前登録制pre-registrationが導入されはじめています。
In null hypothesis testing, the design of the sample size is very important. As already mentioned, if the sample size is large, it is easier to judge it as significant. This is inevitable when judging by the $p$ value, but taking advantage of this and collecting many samples to make a claim that is more than the fact is like hacking the null hypothesis testing. This is a typical example of a bad research practice called p-hacking. Therefore, when conducting a test, it is necessary to first declare "what kind of effect is expected and how many samples should be taken to verify this", and then test and judge. If you test without making this declaration, you may be criticized for "changing the sample size to make it significant". You may not have to design a sample size or declare the sample size in experiments conducted in undergraduate classes or graduation theses, but in the academic world, a pre-registration system is beginning to be introduced where this declaration is communicated to the academic society before starting research.

Indeed, one of the challenges is knowing in advance how big the effect size will be before starting research. Even so, if there is preceding research, that research already contains both a sample size and an effect size calculable from actual data, so it is possible to calculate what kind of research has what kind of effect size.

Before conducting a study, doing these calculations in advance is referred to as a "power analysis". Power analysis is conducted in two types of cases; for sample size planning and for checking how much effect size was observed after the research. Additionally, there are statistical packages and R functions for doing these calculations, so in practice, these will be used for calculations.
