\chapter{Relationship between Probability Distributions and Data}
\label{m23_likelihood}
In hypothesis testing, the approach has been to test the average causal effect by referring to the probability distribution of sample statistics such as means and (unbiased) variances, and making judgments based on the results. Hypothesis testing is thus a combination of methods for estimating population parameters and logic for determining the results. The method for estimating the population parameters is to use the sample mean and unbiased variance, which is called the method of moments. In contrast, there is a method for estimating the parameters by adjusting the probability distribution modeled on the data to the closest form, and using that value as the estimate. Here, we will explain this method, called maximum likelihood estimation, and the concept of likelihood on which it is based.

\section{Probability and Likelihood Functions}
Let's think again about the relationship between probability and data.

Assuming we know the shape of the probability distribution and its parameters, such as a Bernoulli distribution with $\theta=0.5$ or a normal distribution with mean $\mu=5$ and standard deviation $\sigma=1$, we can consider how the data might arise from it. Let's use the example of a Bernoulli distribution since it is easy to understand\footnote{See Section \ref{bernoulli_distribution}, p.\pageref{bernoulli_distribution} in Lecture \ref{m07_probability}.}. If we know that the outcome of a coin toss follows a Bernoulli distribution with $\theta=0.5$, we would expect to see an equal number of heads (1) and tails (0). If $\theta=0.7$, we would expect to see more heads than tails.

When we think about probabilities, we usually think the other way around. In reality, we often observe a large number of heads when flipping a coin, such as H, H, T, H, H.... This leads us to question whether the parameter for this coin is not $\theta=0.5$ (it's not fair - it's a rigged coin). This is a situation where the realized values are known, but the parameter is unknown. When conducting research, we may have data, but the parameter is still unknown. The population mean and variance, which have been inferred thus far, are also parameters, but they were inferred based on the data that was available.

Let's think a little more deeply. The Bernoulli distribution is a probability distribution as follows.
\[ p(k) = \theta^k (1-\theta)^{1-k} \]
Here, k takes either 1 or 0. The probability of obtaining heads, p(1), is given by $\theta^1(1-\theta)^0 = \theta$\footnote{The rule of exponentiation states that any number raised to the power 0 is equal to 1.}, and the probability of obtaining tails is p(0) = $\theta^0(1-\theta)^k = (1-\theta)$. This can be expressed mathematically. For example, if $\theta$ is set to 0.7, the probability of obtaining heads is 0.7 and the probability of obtaining tails is 0.3, which is easy to understand.

In the situation where $\theta=0.7$ is known, rather than the usual approach, we want to proceed with the consideration of the unknown parameter ($\theta$ symbol) while not modifying the TeX code. If a coin comes up with heads twice in a row, then the probability is $\theta \times \theta = \theta^2$. If it comes up three times in a row, then it is $\theta^3$, and if it comes up heads, heads, tails, tails, heads, then it is $\theta^3\times (1-\theta)^2$, which can be expressed using symbols. Here, $\theta$ is a number that takes a value between 0 and 1, so we can draw a graph of the function with $\theta$ as the x-axis and $y=\theta^3\times (1-\theta)^2$ as the y-axis. The abbreviation \emph{ML} is sometimes used.

\section{Log-likelihood function}
By the way, you might think that calculating the maximum value of likelihood is a bit complicated because it involves differentiation. However, once you plug in specific numerical values, it is not that difficult. For example, let's consider the case of a Bernoulli trial (coin toss) where out of 5 tosses, 3 resulted in heads and 2 in tails. If $\theta=0.3$, then the maximum likelihood can be calculated as:
\[ 0.3^3 \times (1-0.3)^2 = 0.3 \times 0.3 \times 0.3 \times 0.7 \times 0.7 = 0.01323 \]
You can calculate it. The maximum likelihood estimate, $\theta=0.6$, is the value where the likelihood is maximized.
\[ 0.6^3 \times (1-0.6)^2 = 0.6 \times 0.6 \times 0.6 \times 0.4 \times 0.4 = 0.03456 \]
One can calculate that it is. Of course, using a computer program such as R would be sufficient for the calculation, but the issue here is that the numbers are small.

Probability never exceeds 1, so when multiplying small numbers together, the number of digits decreases rapidly. A computer calculates multiplication continuously when told to do so, but internally, it is just a series of 0/1 bits that have a physical limit to how many can be used to calculate infinitesimal numbers. In fact, every computer has a limit to the numbers it can assign, including older computers with 32-bit units or even as little as 8-bit units. A 64-bit OS assigns 64 bits of information to each number, which translates to about 20 digits. So although a computer can calculate a few coin tosses, as it gets up to 10 or 20, it nears its limit, and eventually, it will issue an error message that it cannot calculate a number that is too small.

\section{Likelihood function of normal distribution}
Talking about logarithms is a computational issue, so it's okay to just keep it as a knowledge in the back of your mind. Instead, I hope you will firmly understand that we can estimate parameters by using function forms as they are. With this method, we don't have to worry about unbiased estimates or standard errors, so you might find this easier. It's important to note that this is considering the "probability of obtaining a certain estimate."
Please note that it is not (since likelihood is not the same as probability). Also, even if you set the parameters to fit the data best, it is meaningless if the probability distribution function (= probability model) that fits the data is wrong. For example, in the case of coin tossing, it is correct to fit the Bernoulli distribution (or binomial distribution), but if you consider other distributions such as the normal distribution, it becomes a story like "the answer comes out, but everything is wrong in the first place". This is called a model misspecification problem, which refers to the fact that we have not been able to choose the appropriate probability distribution function. However, as we have seen so far in psychology, we can assume the normal distribution for many data. Please remember that we are trying to understand the phenomenon by assuming the normal distribution as a "hypothesis" or "model".

Come to think of it, what happens to maximum likelihood estimation using the normal distribution? The normal distribution is adjusted by two parameters: the mean $\mu$ and the standard deviation $\sigma$, so it involves solving a system of equations with both parameters unknown.

Let's consider an example using numerical values. We'll look at the same story from the first example in Lecture \ref{m16_inference}: "During a physical examination at a small school, three people were measured. Their heights were 165cm, 173cm, and 182cm, respectively." To simplify things, let's assume that we already knew that the population standard deviation was $\sigma = 10$. By doing this, we can narrow down the parameter we need to estimate to just one, which is $\mu$, just like in the previous example of the Bernoulli trial. What we want to know here is what kind of $\mu$ value would give us the data $\{165, 173, 182\}$ from $N(\mu,10)$.

Assuming $\mu=160$, let's consider the likelihood of the number 165 coming from $N(160,10)$. First, let's review the formula for the normal distribution. It is expressed as follows:

\[ 	f(x)= \frac{1}{\sqrt{2\pi \sigma^2}} exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right) \]
Assuming that the data $x=165$ was obtained under the parameters $\mu=160, \sigma=10$, we can substitute the numbers into the equation.
\[ \frac{1}{\sqrt{2\pi \times 10^2}} \exp\left(-\frac{(165-160)^2}{2\times 10^2}\right) = 0.03520653 \]
It becomes\footnote{Just to confirm, the number $\pi$ is the value of approximately $3.1415...$ and the expression $\exp(x)$ represents the exponential function defined as $\exp(x)=e^x$ where $e$ is a constant with an approximate value of $2.71828...$. Therefore, there are no unknown variables in this equation.}.
Likelihood of obtaining the data 173 from the normal distribution $N(160,10)$ is similarly calculated as follows:
\[ \frac{1}{\sqrt{2\pi \times 10^2}} \exp\left(-\frac{(173-160)^2}{2\times 10^2}\right) = 0.01713686 \]
Likelihood with the data point of 182 is also mentioned.
\[ \frac{1}{\sqrt{2\pi \times 10^2}} \exp\left(-\frac{(182-160)^2}{2\times 10^2}\right) = 0.003547459 \]
