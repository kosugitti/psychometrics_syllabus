\chapter{Maximum Likelihood Estimation in Regression Analysis}
\label{m24_maximum_likelihood}
Last time, we learned about the \textbf{maximum likelihood estimation method}, which involves interpreting the likelihood function as a function of the unknown parameter(s), where the parameter(s) are assumed to be unknown among the variables in the probability distribution function, and estimating the value of the parameter(s) that maximize(s) this function.

This time, we're going to apply this to linear models. We've been explaining linear models from the first term to now, touching on them from time to time. First, we touched on regression analysis in Lecture \ref{m09_Regression}, then moved on to multiple regression analysis in Lecture \ref{m10_MultipleRegression}, and then expanded into factorial design. In the second term, we talked about inferential statistics, the combination of factorial design and hypothesis testing, and discussions on analysis of variance (ANOVA). The estimation method used there was the method of moments, which uses sample mean and unbiased variance. The idea of dividing the sum of squares by the degree of freedom, obtaining the mean square, and comparing the ratio to the F-distribution is similar to the idea of considering population parameters from mean and variance.

In contrast, the previous approach was to consider parameter estimation from the likelihood. While the estimated values are the same, it is important to note the difference in approach as we move forward to discuss maximum likelihood estimation for linear models.

\section{Regression Analysis and Error Distribution}
Let's review the linear models, especially the model of simple regression analysis, without modifying the TeX code.

When given a set of data pairs, $x_i$ and $y_i$, a linear model is fitted to predict $y$ using the variable $x$. The linear model is the simplest linear equation and is expressed as follows:
\[\hat{y}_i = b_0 + b_1 x_i \]
Assuming that an error $e$ is added to the predicted value $\hat{y}$, the actual value $y$ is obtained.
\[ y_i= b_0 + b_1 x_i + e_i  \]
So, as you may recall from the previous lecture on \keytermE{least squares regression} in section \ref{m08_CorrelationCausation}, the method involves fitting this equation to the data and finding the intercept that minimizes the errors within the data. However, we only talked about data at hand and not much about the essence of inferential statistics - that the data we have is just a sample and we want to consider how it behaves in the population as a whole.

By the way, in this case, we assumed a normal distribution for the error. Since the error is the accumulation of various unknown factors, we do not know whether it will increase or decrease. However, extreme errors are unlikely to occur, and if we assume that errors around the mean are more likely to occur, we can expect a bell-shaped curve that is symmetric about a single peak. Additionally, we are considering random errors in this case. \footnote{There are also systematic errors, which are constant errors that always occur, such as a scale that is off even when nothing is being measured. We will not address this correction in this case. The thing to watch out for when taking measurements is the random error that cannot be eliminated even with care.} Therefore, we aim to fit the model by minimizing $e_i = y_i - \hat{y}_i$ over the entire dataset. This is a review of the previous period.

\section{Probability Models}
The goal here is to consider this linear model as a probability model and to perform maximum likelihood estimation. Please recall the previous session, Section \ref{thinkWithDistribution} on page \pageref{thinkWithDistribution} where we discussed this matter. As it is an essential piece of information, let us explain it again.

To perform maximum likelihood estimation, it is necessary to represent the regression analysis equation as a probabilistic model. Among the symbols that appear in the previous model equation, the one that stochastically changes is the error $e$.
And this is natural to assume that it follows a normal distribution. In formula, it can be written as,
\[ e_i \sim N(0,\sigma) \]
The average error is confirmed to be zero here. Also, although the average is zero, the error comes out with a certain range of spread, which is represented as a standard deviation $\sigma$.

Now, we know that the error is determined stochastically, but the relation between $x$ and $\hat{y}$ is not probabilistic. While the intercept and slope are unknowns (which we denote as $\beta_0$ and $\beta_1$ representing the intercept and slope in the population, respectively), if they are known, the relationship between $\hat{y}_i$ and $x_i$ is deterministic. In other words, instead of using the symbol $\sim$ to express "following a probability distribution," we can use the equal sign to describe that "the left-hand side is \textbf{equal} to this".
\[ \hat{y}_i = \beta_0 + \beta_1 x_i \]
This is a linear model. The ideal prediction value $\hat{y}$, which is not disturbed by errors, can be described as a linear function of $x_i$. However, actual data $y_i$ comes with errors added to $\hat{y}$.
\[ y_i = \hat{y}_i + e_i  \]

\section{Maximum Likelihood Estimation of Probabilistic Models}

If you can write a probability model in this way, then all you have to do is estimate the unknown parameters so that the data is most likely to come from this probability model.
Just to reconfirm, in this model $y_i \sim N(\beta_0 + \beta_1x_i, \sigma)$, the three unknown values are $\beta_0, \beta_1$, and $\sigma$.


If we properly write the formula for normal distribution, the probability density function that involves a value $x$ can be expressed as:
\[ p(x) = \frac{1}{\sqrt{2\pi \sigma}}exp\left( - \frac{(x-\mu)^2}{2\sigma^2}\right)\]
Without modifying the TeX code, please translate this Japanese text into English:

"It means that we will substitute the formula $\beta_0 + \beta_1 x_i$ for the average $\mu$."

As the structure is already complex, there may be parts that are hard to visualize, but the probability density of obtaining a certain data point $y_i$ is given by the following equation in Japanese:
\[ p(y_i) = \frac{1}{\sqrt{2\pi \sigma}}exp\left( -\frac{(y_i-\mu)^2}{2\sigma^2}\right)\]
So, substituting $\mu=\hat{y_i} = \beta_0 + \beta_1 x_i$, we have
\[ p(y_i) = \frac{1}{\sqrt{2\pi \sigma}}exp\left( -\frac{(y_i-\beta_0 - \beta_1 x_i)^2}{2\sigma^2}\right)\]
You are a translator.

The data is denoted as $i=1,2,\cdots,N$, and it is assumed that they are independently obtained from the same population (i.i.d.). In other words, when all of these data are simultaneously available, the likelihood $L$ can be considered as the product of the above probability density function ($p(y_i)$) for each data point. (Note: Think back to when a coin toss resulted in heads, heads, and tails, and how the probability of this was $\theta \times \theta \times (1-\theta)$!)
"To take the sum of $i$ from 1 to $n$, we express it as $\sum_{i=1}^N x_i=x_1+x_2+\cdots+x_N$. Similarly, the total product obtained by multiplying all of them is represented as:"
\[ x_1 \times x_2 \times \cdots x_N = \prod_{i=1}^N x_i \]
The passage says: "Here, we use the symbol $\prod$, which represents the product, and when we express the likelihood $L(Y_i)$ using this symbol, it is represented as follows."

\[ L(y_i | \beta_0,\beta_1,\sigma) = \prod_{i=1}^N \frac{1}{\sqrt{2\pi \sigma}}exp\left(- \frac{(y_i-\beta_0 - \beta_1 x_i)^2}{2\sigma^2}\right)\]

The notation $L(y_i | \beta_0,\beta_1,\sigma)$ represents the likelihood, using the notation of conditional probability, that is borrowed to express the probability of $y_i$ given $\beta_0, \beta_1$, and $\sigma$ are given. The vertical line denotes "given," or the conditionality of the probability.

Now, this involves multiplying probabilities (densities), which results in very small numbers and makes actual calculation quite difficult. Therefore, as we learned last time, let's not use the likelihood itself, but take the \keytermE{log-likelihood} instead, and find its maximum value. Taking the logarithm changes multiplication to addition, so the product symbol $\prod$ changes to the sum symbol $\sum$, and the log-likelihood function becomes as follows:

\[ \log L(y_i | \beta_0,\beta_1,\sigma) = \sum_{i=1}^N \log \left[ \frac{1}{\sqrt{2\pi \sigma}}exp\left( -\frac{(y_i-\beta_0 - \beta_1 x_i)^2}{2\sigma^2}\right)\right]\]

This appears to be very complicated! Furthermore, since it involves three variables, $\beta_0$, $\beta_1$, and $\sigma$, it will require solving a system of differential equations.
Of course, it's no problem. This complicated calculation will be done by R, so we don't need to worry about anything.

Furthermore, the values of $\beta_0$ and $\beta_1$ obtained from this maximum likelihood estimation \underline{coincide with the results of the least squares method}.
So essentially, all that needs to be done is to perform a simple regression analysis.

As can be seen, regardless of the method used, the same estimated values (intercept $\beta_0=-124.918$ and slope $\beta_1=1.167$) are obtained. A slightly unrelated side note is that the final line of the maximum likelihood estimation shows that the $F$ statistic has degrees of freedom $F(1,327)=226.9$ and its $p$-value is also calculated. This reveals that there is a connection between linear models and factorial designs and the null hypothesis testing in these cases\footnote{Here, the testing is performed against the null hypothesis that all explanatory variables (in this example, there is only one explanatory variable since it is simple regression) except the intercept have zero slopes.}.

As I mentioned before, even if the methods differ, the fact that the estimate values are the same is a natural result, as they are estimating the same parameter. It's like reaching the peak of a mountain; even if there are multiple routes, the goal is the same.
If there were any differences, it would be that in the case of maximum likelihood estimation, the standard deviation of the error $\sigma$ is also estimated. There is no mention of $\sigma=...$ in the results, but if you look closely, the minimum and maximum values, quartile deviation, median, and other statistics of the residuals $e$ are shown in the \verb|Residuals| section, indicating that errors are assumed to be distributed.

This time, we conducted a simple regression analysis with one explanatory variable, but the same applies to multiple regression analysis where the number of explanatory variables increases. The \verb|lm| function returns estimation values that maximize the likelihood, assuming that the data is obtained from a normal distribution.

You may wonder why we go through such a roundabout way of discussing the least squares method and the maximum likelihood method when, in the end, they yield the same result.
The important point is that the linear model has become a probability model. By becoming a probability model, its range of application expands, which is one answer.
However, there is one more important thing to note. It relates to the third method of estimating the population parameter, which is called the Bayesian estimation method. This third method also uses a probability model, but the details will be explained in the next lecture.
