ランダム切片モデル - Random Intercept Model
Family - The distribution of the response variable is assumed to be Gaussian.
Links - The link function for the mean and standard deviation is identity function.
Formula - The model formula specifies that the response variable is modeled by time and the random intercept.
Data - The dataset used for the analysis is Example3 with 12 observations.
Samples - The analysis is run with 4 chains, each with 2000 iterations, warmup of 1000, and thinning rate of 1. The total number of post-warmup samples is 4000.
Group-Level Effects - The random intercept has a group-level effect, which is modeled by ID. The number of levels for ID is 4.
Population-Level Effects - The average response variable has an intercept of 7.36. The effect of time is modeled by timetime2 and timetime3.
Family Specific Parameters - The standard deviation of the response variable is estimated to be 1.31.
Samples were drawn using sampling(NUTS). For each parameter, Bulk_ESS and Tail_ESS are effective sample size measures, and Rhat is the potential scale reduction factor on split chains (at convergence, Rhat = 1).
