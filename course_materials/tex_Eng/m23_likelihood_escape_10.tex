\begin{itemize}
   \item \keytermE{確率密度関数}{かくりつみつどかんすう}{probability density function} has the same form, and when the parameters are unknown, it is called the likelihood function.
   \item The estimation method that finds the parameter values that maximize the likelihood is called maximum likelihood estimation.
   \item Since likelihood calculations tend to result in small numbers, it is common to use the logarithmic likelihood for computation. Taking the logarithm does not change the location of the peak. 
\end{itemize}
