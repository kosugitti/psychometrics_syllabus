Of course, it is possible to solve regression analysis by the Bayesian method, just as it was solved by the maximum likelihood method. In this lecture, we will consider Bayesian estimation of linear models and factorial designs. In the estimation using the Bayesian method, we will evaluate the estimation method while paying attention to how to set the prior distribution and how to interpret the results, and while comparing the results with the maximum likelihood method. Also, in psychology, there are many studies that estimate the average causal effect by combining a normal distribution model and a factorial design method, but this time we will consider how to interpret the parameters to be estimated in the factorial design and the posterior distribution using the Bayesian method.

\section{Probability model of Regression Analysis}
% 少し話が横道にそれました。3つの推定法のまとめが終わったところで，回帰分析の最尤推定，ベイズ推定の話に進みましょう。
Our conversation has drifted a bit. Now that we've finished summarizing the three estimation methods, let's move on to discuss maximum likelihood estimation and Bayesian estimation in regression analysis.

% 改めて，回帰分析の式を確認しておきます。データの組，$X_i,Y_i$があった時に，変数$X$をつかって$Y$を予測する，線形モデルを当てはめるということを考えるのでした。線形モデルは最も単純な一次式で，
Let's confirm the formula for regression analysis again. We think about fitting a linear model to predict Y using variables $X$ when there is a set of data, $X_i, Y_i$. The linear model is the simplest linear equation,
\[\hat{Y}_i = b_0 + b_1 X_i \]
とし，予測値$\hat{Y}$に誤差$e$がついて実現値$Y$が得られると考えて，
\[ Y_i= b_0 + b_1 X_i + e_i  \]
% とするのでした。第\ref{chapter8}講でやった最小二乗法は，この式をデータに当てはめ，データの中で誤差が一番小さくなるように切片を求める，という方法だったことを思い出してください。あくまでも手元のデータの話しかしていませんでしたが，これに推測統計学のエッセンス，つまり手元のデータは標本に過ぎず，母集団の中でどうか，ということを考えたいと思います。
Assume so. Remember that the method of least squares we covered in Lecture \ref{chapter8} was a method of fitting this formula to the data and finding the intercept where the error is minimized. We have only been talking about the data at hand, but now I would like to consider the essence of inferential statistics, that is, that the data at hand is nothing but a sample, and I want to think about how it is in the population.

% 最尤推定をするためには，この回帰分析の式を確率モデルで表現しなければなりません。このモデルの中に出てくる記号のなかで，確率的に変わるのは何かと言われれば，最もわかりやすいのは誤差$e$です。そしてこれは，ガウスの天才的な発想のおかげで正規分布するということがわかっています。数学的な表現をすると，
In order to perform maximum likelihood estimation, this regression analysis formula must be expressed in probabilistic models. Among the symbols that appear in this model, the one that changes probabilistically and is easiest to understand is the error $e$. Thanks to the ingenious idea of Gauss, we know that this follows a normal distribution. In mathematical terms,
\[ e_i \sim Normal(0,\sigma) \]
ということになります。ここで誤差の平均が0である，ということを再確認してください。また，平均は0ですが，誤差は一定の幅で散らばって出てきますので，これを標準偏差$\sigma$で表しています。

さて，誤差が確率的に求まることがわかりましたが，$X$と$\hat{Y}$の関係は確率的ではありません。切片や傾きは未知数ですが(母集団での切片と傾きのことになるので$\beta_0,\beta_1$と表記しますが)，これがわかりさえすれば$\hat{Y}_i$と$X_i$の関係は確定的です。つまり，「確率分布に従う」を表す$\sim$という記号ではなく，「左辺はこのようになって\textbf{いる}」ということを記述するために，$=$を使って書くことができます。
\[ \hat{Y}_i = \beta_0 + \beta_1 X_i \]
% これが線形モデル，です。誤差に邪魔されることがない，理想的な予測値$\hat{Y}$は，$X_i$の一次関数の形で記述できる，ということです。実際のデータ$Y_i$は$\hat{Y}$に誤差がついて出てくるものですから，
"This is a linear model. The ideal predicted value $\hat{Y}$, which is not disturbed by error, can be described as a linear function of $X_i$. The actual data $Y_i$ is what comes out with an error on $\hat{Y}$."
\[ Y_i = \hat{Y}_i + e_i  \]
と書くことができます。

さて，これらを組み合わせていきましょう。最後の式から$\hat{Y}$を消去する(線形モデルで代入する)と，
\[ Y_i =  \beta_0 + \beta_1 X_i+ e_i \]
% ということになります。ここで$ \beta_0 + \beta_1 X_i$のところは確率的に変わるものではなく，定数であることに注意します。
It turns out to be the case. Note that $ \beta_0 + \beta_1 X_i$ is not something that changes probabilistically, but is a constant.
\input{text1_chap26old_escape_01}
% 誤差$e_i$は平均0を中心に確率的に散らばりますが，その前のところは確率的ではありませんので，これを組み合わせた式全体としては，最後に確率的な散らばりがひっついているような形になります。
The error $e_i$ is probabilistically scattered around an average of 0, but the previous part is not probabilistic. Therefore, when these are combined, the entire formula appears to have probabilistic scatter attached to the end.
\input{text1_chap26old_escape_02}

% さて，この「確率的でないところ」が確率分布の中に入り込むとしたら，誤差$e_i$の平均値を$\beta_0 + \beta_1 X_i$だけズラすような作用をすることになります。すなわちデータ全体で，
Now, if this "non-random part" enters into the probability distribution, it will act to shift the average value of the error $e_i$ by $\beta_0 + \beta_1 X_i$. That is, for the entire data set,
\[ Y_i \sim Normal(\beta_0 + \beta_1 X_i , \sigma) \]
と書くことができます。これが回帰分析の確率モデルになります。

\section{回帰分析の最尤推定，ベイズ推定}
\subsection{最尤推定の場合}
このようにして確率モデルを書くことができれば，あとはこれにしたがって「データがこの確率モデルから出てくる尤もらしさが最も高くなるのは，どういった$\beta_0, \beta_1, \sigma$の時なのか，という推定をすれば良いことになります。

正規分布の式をちゃんと書くと，$x$という値が出てくる確率密度は
\[ p(x) = \frac{1}{\sqrt{2\pi \sigma}}exp\left( \frac{(x-\mu)^2}{2\sigma^2}\right)\]
% となります。この平均$\mu$のところに$\beta_0 + \beta_1 X_i$という数式が入ってしまっているのでイメージしづらいところがあるかもしれませんが，あるデータ$Y_i$が得られる確率密度は
This might be difficult to visualize since the formula $\beta_0 + \beta_1 X_i$ is included in this average $\mu$. However, the probability density for obtaining a certain data $Y_i$ is as follows:
\[ p(Y_i) = \frac{1}{\sqrt{2\pi \sigma}}exp\left( \frac{(Y_i-\mu)^2}{2\sigma^2}\right)\]
ですから，$\mu=\hat{Y_i} = \beta_0 + \beta_1 X_i$を代入して
\[ p(Y_i) = \frac{1}{\sqrt{2\pi \sigma}}exp\left( \frac{(Y_i-\beta_0 - \beta_1 X_i)^2}{2\sigma^2}\right)\]
% となります。データは$i = 1,2,\cdots,n$とあり，それらが同じ母集団から独立に得られています。手元に同時にこれらのデータが出揃うときの尤度$L$は，上記の確率密度($p(Y_i)$)を全部掛け合わせたもの\footnote{コインが表，表，裏，と出たら$\theta \times \theta \times (1-\theta)$と欠けたことを思い出して！}になりますから，総積の記号$\prod$を使って書くと
The data is such that $i = 1,2,\cdots,n$ and they are independently obtained from the same population. The likelihood $L$ when all these data are available at once is the product of all the above probability densities ($p(Y_i)$). Please remember that if a coin shows heads, heads, tails, it would be $\theta \times \theta \times (1-\theta)$. So, if we use the product sign $\prod$ to express it.
\[ L(Y_i | \beta_0,\beta_1,\sigma) = \prod_{i=1}^N \frac{1}{\sqrt{2\pi \sigma}}exp\left( \frac{(Y_i-\beta_0 - \beta_1 X_i)^2}{2\sigma^2}\right)\]
だということになります。$L(Y_i | \beta_0,\beta_1,\sigma) $というのは，$\beta_0,\beta_1,\sigma$が決められた時の，という条件付き確率の書き方を借りたLikelihoodという意味です。これは確率(密度)の掛け算になりますから，すごく小さな数字になって計算しにくいので，実際には対数をとって
\[ \log L(Y_i | \beta_0,\beta_1,\sigma) = \sum_{i=1}^N \log \left[ \frac{1}{\sqrt{2\pi \sigma}}exp\left( \frac{(Y_i-\beta_0 - \beta_1 X_i)^2}{2\sigma^2}\right)\right]\]
% と計算することになります。というか，実際にはRがこれで計算してくれるわけです。
It turns out that you will do the calculations. Or rather, in reality, R does the calculations for you.

% ちなみにこの最尤推定の結果は，最小二乗法の結果と一致します。
By the way, the result of this maximum likelihood estimation corresponds with the result of the least squares method.
% \subsection{ベイズ推定の場合}
\subsection{In the Case of Bayesian Estimation}
% ベイズ推定の場合も，尤度は基本的に同じです。違うのはわからないものを確率で表現する，というところにあります。この時の未知数はと言えば，$\beta_0, \beta_1, \sigma$の3つですから，これに対して何らかの事前分布(無情報か弱情報か，あるいは先行研究に基づくものでも)を仮定してやると，事後分布が計算できるということになります。
In the case of Bayesian estimation, the likelihood is basically the same. The difference is that unknowns are expressed probabilistically. The unknowns at this time are $\beta_0, \beta_1, \sigma$, so if we assume some prior distribution (whether it is uninformed, weakly informed, or based on prior research) for these, we can calculate the posterior distribution.
\input{text1_chap26old_escape_03}
% データと組み合わせた結果として，$\beta_0, \beta_1, \sigma$の事後分布が得られます。最尤推定や最小二乗法の場合と違って，推定値が点で出てくるのではなく，確率分布として出てくることに注意してください。答えは分布そのものですが，その事後確率が最大になる\keyterm{MAP推定値}{MAPすいていち}{Maximum A Posterirori Estimation}や，平均値である\keyterm{EAP推定値}{EAPすいていち}{Expected A Posteriroi Estimation}を使って代表させることができます\footnote{次回説明しますが，$\sigma$の分布は負になることもないので歪んだ分布になりますから，EAP推定値よりはMED推定値やMAP推定値の方が代表値としては良い，ということになります。}。ベイズ法で推定した場合も，最尤推定や最小二乗法による推定結果と大きく変わることはありません。具体的な実践例については，次回の演習でみていくことにします。
As a result of the combination with the data, you obtain the posterior distribution of $\beta_0, \beta_1, \sigma$. Unlike the maximum likelihood estimate or the least squares method, note that the estimated value does not appear as a point, but as a probability distribution. While the answer is the distribution itself, it can be represented using the Maximum A Posteriori (MAP) estimate, where the posterior probability is the highest, or the Expected A Posteriori (EAP) estimate, which is the average value. Note that, as we'll explain next time, since the distribution of $\sigma$ cannot be negative, it will become a skewed distribution, so the MED estimate or the MAP estimate is better as a representative value than the EAP estimate. Even when estimated by the Bayesian method, the estimation result does not differ significantly from the maximum likelihood estimate or the estimation by the least squares method.
