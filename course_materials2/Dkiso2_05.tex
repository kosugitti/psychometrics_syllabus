\section{現代テスト理論の特徴}
現代テスト理論の特徴は，項目母数と被験者母数の分離，完全情報最尤推定，項目情報曲線による信頼性の表現，項目プールがあれば事前にテストの平均点を設計できることがあげあられる。またComputer Adopted Testの形式を用いることでテストのあり方そのものも変わってしまう。ただし実際には，膨大な項目プールが必要であること，事前に項目母数を準備しておく必要があること，その他「公平性のために新しいテストでなければならない」という信念などが弊害となって実践的には敷居が高いことなどを解説する。
\section{段階反応モデル}
 テスト理論はバイナリデータに対する分析だが，多段階の反応に拡張する方法がいくつか考えられている。一つは段階反応モデルとよばれるもので，これを使うと適当な反応弾回数がデザインできるなど利点は大きい。またその考え方はリッカートのシグマ法を洗練したものであるとも言え，せめてこうした方法を使わないと多段階反応を適当に分析できていない。統計パッケージなどの実装も進んでいるので，計算コストはほとんど障壁にならない。また，ポリ子リック相関係数を用いた因子分析を実行すると，段階反応モデルのパラメータに変換できることから，因子分析とテスト理論が同じものであったことを再確認することができる。

\section{因子分析の歴史と展開}
  因子分析モデルもテスト理論も潜在変数モデルとしては同じであり，一方が単因子・二段階，他方が多因子・多段階であることが道を分つ。またその性質から，一方が因子得点に，他方が因子構造に着目するため，テストの構成についての考え方が異なることにも注意する。繰り返しになるが，統計パッケージ上の実装は進んでいるので，どちらを使うにしても特に苦労することなく，積極的にカテゴリ軽モデルを推進していくべきである。

% 心理学における測定とは，目に見えない質的なもの（「心」「能力」「態度」など）を目に見える形，数字に表すことです。「人の知能とはどういうものか」，「性格というのは何がどれほどあるのか」といった問いから研究が始まりました。知能検査，性格検査などで様々な検査をし，反応を記録し，その結果から目に見えない心を描き出そうとしたのです。心理測定法は検査法，言い換えればテストの研究でもあります。

% テストといえば我々は学校という場で，数えきれないほどのテストを受けてきました。国語のテスト，算数のテスト，スポーツテストや音楽のテストなど，あらゆるところで検査されていた，ともいえます。テストを受けると点数がつけられます。この点数がすなわち個人の能力(ability)であり，国語のテストは国語の能力を，算数のテストは算数の能力を測定しています。知能検査も知能というその人の特性(trait)を数値化するのが目的なのです。

% テストというのは，普通複数の項目からなります。一つの問いに答えられなかったからといって、その人の能力がゼロである，と考えるのはあまりにも性急だからです。例えば算数のテストをするときは，簡単な問題から難しい問題まで十数問の問題に回答させ，その総合的な回答パターンからその人の算数能力を見積もるわけです。学力テストの場合は比較的「何の」能力を測っているかがわかりやすいですが，知能や性格といった心理的特徴の場合は，そうしたものが本当にあるのかどうか、あるとしてもいくつあるのか（知能は一つなのか，いくつかの分類が出来るのか。性格はどうか、など）が事前に明らかなではありません。

% そこで，テスト理論は二つの方向に分かれていくことになります。
% 一つは学力テストのような，試験によってその人の能力を採点する方向です。テストの特徴は，回答が○か×か，正答か誤答かという二段階で表されるというところにあります。また，算数のテストは算数の能力，英語のテストは英語の能力，と測りたいものが明確で単一のものだと仮定することが出来ます。そしてその目的は個々人の採点であり，いかに正確に個人差を描き出すことが出来るか、というところが中心的関心事になります。

% もう一つは心理尺度のような，目に見えない人の性質の構造を明らかにする方向です。心理尺度は知能や性格だけでなく，社会的態度なども含みます。例えば政治的態度として，自由主義的か社会主義的か，革新的か保守的かといった方向性が考えられ，その回答パターンも「強く反対」とか「やや同意できる」といった数段階の程度があると考えられます。ここでの目的は全体に共通する要素やその構造であり，何種類に別れて要素間の関係はどうなっているのか、というところが中心的関心事になります。

% 前者が項目反応理論，後者が因子分析という名称となって広まりましたが，いずれも因子分析の系列であり，因子得点に注目するか因子構造に注目するか，データが連続がバイナリか，因子が一つか複数か，というモデル内の違いがあるだけともいえます。項目反応理論は，そもそもは「単因子」，「二値変数」の因子分析です。因子分析は一般に「多因子」，「連続変数」です。

% この違いは分析のときにも異なる思想を生みます。
% 因子分析をしているときに，共通性が低い項目は削除して再度分析する，とか，単純構造の原則(一つの項目は一つの因子に対応しているべきであるという考え方)に則り，複数の因子に寄与した項目は削除して再度分析する，と教わった人がいるかもしれません。
% 因子分析は既に述べた通り，知能，性格，態度の研究で展開され，美しい構造を見つけ出すことに狙いがありますから，この美しさを損なうもの(項目)は取り除く，という方向に行きがちです。

% 一方で，項目反応理論はテスト理論の生まれです。もちろん回答者の能力や特性を測定するのに優れた項目とそうでない項目，という峻別はしますが，中でも「この項目は測定能力の偏差値30程度の回答者を測定するのに適している」とか，「偏差値70程度の回答者を測定するのに適している」という判断をすることが出来ます。偏差値30や70を測定するのに適した項目とは，非常に簡単（ほとんどの人が正答する）だったり，非常に難易度が高い（ほとんどの人が誤答する）項目です。心理尺度でいうと床効果，天井効果がみられる項目とされる，どちらかに偏った分布をもつ項目です。しかし，それを捨てるということにはならず，どのような項目でも回答者の能力を推定するための情報量がゼロではない，という考えから，様々な項目をどんどんためていく方向にいきがちです。項目反応理論の文脈では，あらゆる人に対する測定を準備しておく必要があり，むしろ回答者の特性にあわせて設問の方を選んだり，事前の項目特性から，前もってテストの項目構成をデザインする，ということを目的とするのです。
