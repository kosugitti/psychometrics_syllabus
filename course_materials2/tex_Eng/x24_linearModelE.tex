Here's where the discrete probability distribution we learned about last time comes in. If the data only takes two values, it's natural to think it follows a Bernoulli Distribution, like the heads and tails of a coin. The Bernoulli distribution is one where the parameter θ indicates "heads" (1), and 1-θ indicates "tails" (0), so there's only one parameter, which basically represents the "probability of heads".
% 今回は野手であれば1，投手であれば0というように考えることにしましょう。野手か投手かを表す変数で，野手になる確率$\theta$が試合数によって変わる(予測できる)ということを考えるのです。

Regarding this prediction method, because we can consider a linear relationship such as "The more games played, the higher probability of being a field player", we will consider the formula $\theta_i = \beta_0 + \beta_1 X_i$. Here, $X_i$ is a variable representing the number of games.

% ところがここで，注意すべきことが1つあります。$\theta$は野手になる(表が出る)確率ですから，0から1の範囲の数字しか取れません。プロ野球の試合数は1試合から140試合ぐらいありますので，この数字をそのまま伸ばしたり($\beta_1$倍)ずらしたり($\beta_0$を加える)しても，0から1の範囲に収めるのは難しそうです。しかも上手くその範囲に収めたとしても，そもそも直線なのでどうあってもデータと合致しないことになるでしょう。そこで，この数字をロジスティック関数で変換することを考えます。
However, there is one important thing to note here. $\theta$ is the probability of becoming an infielder i.e., the probability of getting a 'Heads' so it can only take numbers within the range of 0 to 1. The number of professional baseball games ranges from one game to about 140 games, so even if we extend or shift this number directly (multiplied by $\beta_1$) or add $\beta_0$, it seems difficult to fit the result in the range of 0 to 1. Moreover, even if we successfully fit it into this range, since it's a linear line after all, it will not match with the data anyway. Therefore, we can consider transforming this number with the logistic function.

Calculating the batting average from the number of hits and the number of at-bats is the same as using the sample average calculated from the actual values of the random variables. In other words, it's an approach using the \keytermL{moment method}{もーめんとほう}, where the sample average becomes the estimated value of the population average. With this method, if you get a hit in your first at-bat on the first day of the season, your batting average is 100%. Or if you don't get a hit in your first at-bat, are you batting .000? Nobody really believes that. In other words, we understand that there is a bias in estimating the overall value from just one occurrence. 

The estimation by the moment method, or the \keytermL{frequentist statistical theory}{ひんどしゅぎとうけいがく}, defines probability as the value that converges as you continue to bat infinitely, or the average of repeated trials. In contrast, in \keytermL{Bayesian statistics}{ベイズ統計学}, probability is used as a measure of certainty, so no matter the outcome of the first at-bat, the true batting average is estimated by combining it with the prior distribution that says "I know it's not really like this".
