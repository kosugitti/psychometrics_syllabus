\begin{itemize}
   \item 一般線形モデルは，正規分布を使った線形モデルで，説明変数が連続変数でも離散変数でも同じ形で表すことができることを示している。
   \item 一般線形モデルの回帰係数をベイズ推定するモデルは，正規分布の位置母数に線形モデルを入れるだけ。
   \item 従属変数が離散変数になると，確率モデルは離散確率分布を使う必要がある。そのためには，説明変数の線型結合をリンク関数を使って変形し，適切な形にして推定する必要がある。これを一般化線形モデルといいます。
   \item 従属変数がベルヌーイ分布に従う例として，ロジット関数をリンク関数としたロジスティック回帰分析の実例をやってみました。
   \item 一般化線形モデルの場合は説明変数がリンク関数で変換されているから，そのまま解釈するのではなく，変換の意味を理解しながら注意深く解釈しよう。
\end{itemize}
