% さてここまでは二水準の平均値差を考えるモデルでしたが，ここからそれを三水準に増やしてみましょう。
Until now, we've been considering a model with two levels of average difference. However, let's try increasing that to three levels from here.
% 水準数が多くなると\keyterm{要因計画}{よういんけいかく}{Factorial Design}や\keyterm{実験計画}{じっけんけいかく}{Experimental Design}といった話になってきます。\keyterm{分散分析}{ぶんさんぶんせき}{ANalysis Of VAriance;ANOVA}は要因計画と帰無仮説検定の合わせ技で，効果がある/ないの判定を分散の比をつかって行うことでした\footnote{忘れた人は，データ解析基礎のテキストに戻って確認してください。}。
When the number of levels increases, it comes to discussions on Factorial Design and Experimental Design. ANOVA (ANalysis Of VAriance) is a combination of factorial design and null hypothesis testing, where decisions are made on whether or not there are effects by using the ratio of variance. If you forgot, please go back and check the basics of data analysis in the text.

% 今回は要因計画をデータ生成モデルから考え，\keyterm{ベイズ推定}{べいずすいてい}{Bayesian Inference}をすることになります。\keytermL{帰無仮説検定}{きむかせつけんてい}のようなYes/No判断はせず，平均値や差の大きさを直接見積もることになるのは，二群の時と同じです。
This time, we will consider the factor plan from the data generation model and perform \keyterm{Bayesian Inference}. Like the \keytermL{null hypothesis test}, there will be no Yes/No decisions, and we will directly estimate the size of the mean or difference, just as we did when dealing with two groups.

% まずは簡単な\keyterm{群間計画}{ぐんかんけいかく}{Between Design}の話から進めましょう。対応のない二群の時のように，それが三群になるモデルですので，モデルの設計図は非常に単純です(図\ref{fig::21_01})。
Let's first proceed from the discussion about the simple \keyterm{Between Design}. Like the times when there is no correspondence between the two groups, it is a model that becomes three groups, so the design diagram of the model is very simple (Figure \ref{fig::21_01}).

Looking at the design drawing, the code can be written just by replacing it as it is. The code written according to the design drawing is in code:\ref{stan::21_01}.

% 最後の\verb|generated quantities|ブロックにあるように，各群の差の分布も計算して出せるようにしてあります。これをみながら，群AとB，AとC，BとCなどどこに差があるのか，その大きさはどれぐらいかということを考えることができます。左の大きさを標準偏差\verb|sig|で割ることで効果量を出すこともできます。
As in the last \verb|generated quantities| block, it is set up to be able to calculate and output the distribution of differences between each group. Looking at this, one can consider where there are differences between group A and B, A and C, B and C, and how large these differences are. The effect size can also be obtained by dividing the size on the left by the standard deviation \verb|sig|.

% 二群の平均値差の時もそうでしたが，検定と違って差の大きさを直接検証できているところがポイントです。また，検定の場合は分析によって有意差が確認できた場合，そのあと\keyterm{多重比較}{たじゅうひかく}{multiple comparison}へと進むのでした。これは帰無仮説が$H_0:\mu_1 = \mu_2 = \mu_3$となっていて，これを否定することから「どこに差があったか」をさらに詳しくみる必要があったからです。この時，統計的検定の繰り返しによって\keyterm{タイプ1エラー}{たいぷ1えらー}{Type I Error}が増えること，すなわち$\alpha = 0.05$と5\% 水準で検定していても，検定を繰り返すと5\% を大きく上回る問題が生じるため，有意水準を調節するなど工夫が必要だという話でした\footnote{お前は何をいってるんだ，と思った人は，データ解析基礎のテキストに戻って確認しておいてください。大雑把に解説しますと，5\%水準というのは一回の判断で間違いが含まれる可能性を5\%にしましょう，という判定基準のことでしたが，二回判定を繰り返すと$1-(0.95^2)=0.0975$と9.75\%水準になってしまうということでした。3群の平均値を比べるときは，3箇所比較する必要があり，\keytermL{t検定}{tけんてい}を3回も繰り返すと5\%水準ではなくなる，という問題です。}。
As it was the case with the difference in average values of two groups, the point is that you can directly verify the size of the difference unlike a test. Also, in the case of a test, if a significant difference can be confirmed by the analysis, it will proceed to \keyterm{multiple comparison}. This was because the null hypothesis was $H_0:\mu_1 = \mu_2 = \mu_3$, and it was necessary to look more in detail at "where the difference was" by denying it. In this case, \keyterm{Type I Error} increases by repeating statistical tests, that is, even if you test at an $\alpha = 0.05$ and a 5% level, if you repeat the test, a problem arises that greatly exceeds 5%, so it was necessary to devise such as adjusting the significance level\footnote{If you are wondering what I'm talking about, please go back to the text of basic data analysis and check. To explain it simply, the term of "5% level" was a judgment standard that let's keep the possibility of making a mistake in a single decision at 5%, but if you repeat the decision twice, it becomes a 9.75% level with $1-(0.95^2)=0.0975$. When comparing the average values of three groups, you need to compare them at three places, and repeating \keyterm{t-test} three times results in a problem of not being a level of 5%.}.


% ところが，\underline{ベイズ推定の場合はこうした問題が生じません}。なぜなら，確率を伴う判断をしていないからです。帰無仮説検定の場合は，「帰無仮説が正しいという条件のもとで」計算された検定統計量($F$値や$t$値)が，帰無仮説の条件下ではどれほど生じやすいかということを考え，その確率$p$値を計算していましたが，この$p$値はパラメータがどこにあるかといった確率ではありません。判断のための指針としての確率に過ぎないのです。一方ベイズ推定する場合，推定されたパラメータの\keytermL{事後分布}{じごぶんぷ}は，パラメータがこの辺りにあるだろう，という確率であり，生成量である差の分布もさの大きさがこれぐらいだろうという範囲，大きさに直接関わる確率です。ですから何\%区間で考えてもいいですし，その判断が間違うかどうかの確率というのは問題に含まれないのです\footnote{もっとも，すべて研究者の仮定したモデルのもとで，という話ではありますから，その仮定が間違っていたら全部意味のない数字である，ということにはなるかと思います。とはいえ，帰無仮説検定もデータが正規分布に従うという仮定で行うのですから，これについてはどっこいどっこい，というところでしょうか。}。検定の多重性の問題が生じない，というのは複雑な要因計画を考える場合には非常に助かりますね。
However, such problems do not arise in the case of \underline{Bayesian estimation}. This is because we are not making judgments with probabilities. In the case of null hypothesis testing, we calculated the test statistic ($F$ value or $t$ value), which is computed "under the condition that the null hypothesis is true", and we thought about how likely it is to occur under the condition of the null hypothesis and calculated its probability $p$ value. But this $p$ value is not a probability of where the parameter is. It is just a probability used as a guide for judgment. On the other hand, when we make a Bayesian estimate, the \keytermL{posterior distribution} of the estimated parameter is a probability that the parameter might be around here. This distribution of differences, too, is a probability directly related to the range, the size, of how much difference there might be. So you can think in terms of any percentage interval, and the probability of making a wrong judgment is not a problem\footnote{Of course, this is all under the assumption of the model proposed by the researcher, so if that assumption is wrong, it can all become meaningless numbers. However, since null hypotheses testing is also based on the assumption that the data follows a normal distribution, this might be a draw.}. The absence of problems with test multiplicity is very helpful when considering complex factorial designs.

\subsection{Transformation of Parameters}
% ところで，先ほどは差の分布を\verb|generated quantities|ブロックで表現しましたが，違う表現も可能です。差分も未知なるパラメータと考えて推定するのです。
By the way, we expressed the distribution of differences in the \verb|generated quantities| block earlier, but other expressions are also possible. Think of the difference as an unknown parameter and estimate it.

% 順を追って説明しましょう。まず，最初の群の平均値を$\mu_1$とします。第二の群平均$\mu_2$は，$\mu_1$と$\delta_1$だけ違う，つまり$\mu_2=\mu_1+\delta_1$と考えるのです\footnote{ここで$\delta$はデルタと読む，ギリシア文字の$d$のことです。先ほどは生成量として\verb|diff|と書いていましたが，ここでは未知のパラメータなのでギリシア文字に書き換えました。}。同様に，第三の群平均$\mu_3$は$\mu_3 = \mu_1+\delta_2$と考えます。こうすると，推定するべきパラメータは$\mu_1,\delta_1,\delta_2$であり，\verb|generated quantities|ブロックを使わなくても，直接差分パラメータを推定できるようになります。これを書いてみたのが，code:\ref{stan::21_02}になります。
Let me explain it in order. First, let's denote the mean of the first group as $\mu_1$. The mean of the second group, $\mu_2$, is different from $\mu_1$ by $\delta_1$, that is, we consider $\mu_2=\mu_1+\delta_1$\footnote{Here, $\delta$ is read as delta, which is the Greek letter for 'd'. I wrote it as \verb|diff| as a generation quantity earlier, but here it's an unknown parameter, so I rewritten it in Greek letters.}. Similarly, the mean of the third group, $\mu_3$, is considered as $\mu_3 = \mu_1+\delta_2$. In this way, the parameters to be estimated are $\mu_1,\delta_1,\delta_2$, and you can directly estimate the difference parameters without using the \verb|generated quantities| block. What I wrote is shown in code:\ref{stan::21_02}.

The \verb|data| block is omitted because there is no difference. As a change, please confirm first that the parameters to be estimated in the \verb|parameters| block have changed.
% 次に\verb|model|ブロックで，3つのデータがそれぞれ\verb|normal(mu1,sig),normal(mu1+delta1,sig),normal(mu1+delta2,sig)|から出てきているように書き変わっています。正規分布の位置パラメータをずらすことで書き換えているのです。
In the next \verb|model| block, it is rewritten as if the three pieces of data are each coming from \verb|normal(mu1,sig),normal(mu1+delta1,sig),normal(mu1+delta2,sig)|. It is being rewritten by shifting the position parameter of the normal distribution.
% 最後にその下，事前分布の設定ですが，差分$\delta_1,\delta_2$は正負どちらにも出てくる可能性があり，その大きさがわかりませんので，平均を0にした正規分布としてあります。
Finally, under that, regarding the setting of the prior distribution, the differences $\delta_1, \delta_2$ could appear on the positive or negative side, and since we don't know their size, they are recorded as normal distributions with a mean of 0.
% これで推定した結果は，先ほどの生成量を使った結果と変わりはありません。数式の展開で書き方が変わっただけで，モデルの形は同じだからです。
The estimated result with this is no different from the result using the previously mentioned production amount. The way of writing changed with the expansion of the equation, but the shape of the model is the same.

% ここで\verb|transformed parameters|ブロックの紹介をしておきましょう。code:\ref{stan::21_02}は悪くはないのですが，モデルのところ，\verb|normal(mu1+delta1,sigma)|としているのがちょっと美しくないですね。元のコードにあった，\verb|normal(mu2,sigma)|のほうがわかりやすいのに，と思った人もいると思います。まあ今の所，そこまで複雑ではないのでそれほど問題にはならないでしょうが，これからもしパラメータが複雑な構造をするようになったとき，尤度のところはもう少しスッキリ書きたいということも生じてくるでしょう。そういうときに\verb|transformed parameters|ブロックを使います。このブロックは，\verb|parameters|ブロックの次に書くもので，言葉の通りパラメータを変形(トランスフォーム)するためのものです。
Let's introduce the \verb|transformed parameters| block here. Code:\ref{stan::21_02} is not bad, but at the model part, writing it as \verb|normal(mu1+delta1,sigma)| is a bit inelegant. Some may think that it would be easier to understand if it was as \verb|normal(mu2,sigma)| in the original code. Well, it's not too complicated for now, so it's not a big issue, but if the parameters become more complex in the future, you might want to write the likelihood part a bit more neatly. That's when you use the \verb|transformed parameters| block. This block is written after the \verb|parameters| block and is, as the name suggests, used to transform parameters.

If you write too messy code, it will be difficult to deal with when problems arise, so it's best to keep your code simple and clear by using these conventions.

% さてここでこのモデルをもう一段階，発展させてみましょう。
Now, let's take this model to the next level and develop it further.
% 今のコードは第一の群，$\mu_1$を基準に，$\mu_2,\mu_3$を構成していました。別に第二，第三の群を基準にしても良かったですよね。つまり基準点は恣意的になっています。
The current code structures $\mu_2,\mu_3$ based on the first group, $\mu_1$. We could have also used the second or third group as the reference, right? In other words, the reference point has been arbitrarily set.
% それで悪いということではないのですが，$\mu_1$だけ特別扱いです。そうではない作法として，全体平均$\mu$を考えて，次のように定式化してみましょう。
It's not that it's wrong, but only $\mu_1$ is treated specially. As a different method, let's consider the overall average $\mu$ and formulate it as follows.

\input{x21_modeling3_escape_05}
% こうすることで，全体平均からの差分としてモデルを表現できます。
By doing this, you can express the model as a difference from the overall average.
% ここで全体平均$\mu$はどういう意味があるでしょうか。群の違いを独立変数，結果のスコアを従属変数とした線形モデルの一環として考えると，全体平均は群を通じて変化のない水平線(図\ref{fig::21_02})という関係を表していることになります。
What does the overall average $\mu$ mean here? If you think of it as part of a linear model with the differences between the groups as the independent variable and the score of the results as the dependent variable, the overall average would represent a constant line (Figure \ref{fig::21_02}) throughout the groups.

% 横一線で群ごとに違いがないのですから，いわばこれは\keytermL{帰無仮説}{きむかせつ}のモデル，すなわち\keyterm{帰無モデル}{きむもでる}{Null Model}とでもいうべきものです。
Since there is no difference between the groups along the horizontal line, this is essentially what can be called a null model, namely a null hypothesis model.

% あるいは，群ごとの平均値の違いはこの全体平均からの差分で表現されます。この群ごとの違いは，その群に入ったからこそ生じた\textbf{効果}であるとも言えます。つまり，$\delta$は効果の大きさなのです。翻ってかんがえると，全体平均は「なんの処置もしなければ理論的にこの値になるはず」という操作なしの状態，天然の状態とでもいえるでしょう。\keyterm{ランダム化比較実験}{らんだむかひかくじっけん}{Randomized Control Trial}は，被験者をランダムに割り付けることによって，平均的に見れば個別の効果が相殺し合うことを用いています。平均化することで誤差が相殺するので群ごとの比較ができますし，群の平均値が変化したということは，その群に属したことの効果が現れたと考えるわけです。帰無モデルの状態は，この個別の効果を相殺させた状態であることを表しています。
Alternatively, the difference in the mean values for each group can be expressed as a deviation from this overall average. This difference within each group can also be described as an \textbf{effect} that occurred precisely because it was included in that group. In other words, $\delta$ is the size of the effect. Conversely, the overall average can be described as the 'natural' state, or the value that should be theoretically obtained if no action is taken. A \keyterm{Randomized Control Trial} assigns participants randomly, using the principle that individual effects cancel each other out on average. By averaging, errors cancel out so comparisons can be made between groups, and a change in the average value of a group indicates the effect of belonging to that group. The state of the null model indicates a state where individual effects have been canceled out.

% さてこのように考えて，これを数式の形，モデルの形に書き起こしていくことを考えましょう。
Now, let's consider transcribing this into the form of mathematical formulas or models, considering it in this way.
% ところがこのままだと，未知のパラメータは$\mu,\delta_1,\delta_2,\delta_3$と4つあることになります。今までは$\mu_1,\mu_2,\mu_3$，あるいは$\mu_1,\delta_1,\delta_2$の3つだったのに，です。同じ数式を書き直しただけなのに，パラメータの数が変わるのはおかしいですね。
However, as it stands, there will be four unknown parameters, $\mu,\delta_1,\delta_2,\delta_3$. Until now, it was three: $\mu_1,\mu_2,\mu_3$ or $\mu_1,\delta_1,\delta_2$. It's strange that the number of parameters changes just by rewriting the same equation.
% 実はこれには1つ，制約が欠けているのです。今回は全体平均$\mu$からの相対比較になっていますから，$\delta_1+\delta_2+\delta_3=0$という関係が隠れていることになります\footnote{もしこれが$=0$にならなければ，全体平均の計算に矛盾が生じますよね。全体平均$\mu$は，$\mu = \frac{1}{3}(\mu_1+\mu_2+\mu_3)$ですから，$\mu = \frac{1}{3}(\mu+\delta_1+\mu+\delta_2+\mu+\delta_3) =\frac{1}{3}(3\mu + \sum \delta_j) = \frac{1}{3}3\mu + \frac{1}{3}\sum \delta_j$となり，最初の項が$\frac{1}{3}3\mu = \mu$ですから，第二の項は$\frac{1}{3}\sum \delta_j = 0$でないと計算があいません！}。
In fact, there is one constraint missing from this. Since we are making a relative comparison from the overall average $\mu$, it is implicit that there is a relationship $\delta_1+\delta_2+\delta_3=0$\footnote{Otherwise, there would be a contradiction in the calculation of the overall average, right? The overall average $\mu$ is $\mu = \frac{1}{3}(\mu_1+\mu_2+\mu_3)$, so $\mu = \frac{1}{3}(\mu+\delta_1+\mu+\delta_2+\mu+\delta_3) =\frac{1}{3}(3\mu + \sum \delta_j) = \frac{1}{3}3\mu + \frac{1}{3}\sum \delta_j$. Here, the first term is $\frac{1}{3}3\mu = \mu$, so the second term has to be $\frac{1}{3}\sum \delta_j = 0$ for the calculation to match!}.
% そこで，この制約をモデルの中に書き込まなければなりません。$\delta_1+\delta_2+\delta_3=0$という式から，変数を移項することでこれを表現します。すなわち$\delta_3 = 0 - (\delta_1+\delta_2)$のようにします。
Therefore, you must write this constraint into the model. This is expressed by rearranging the variables from the equation $\delta_1+\delta_2+\delta_3=0$. That is, it's like $\delta_3 = 0 - (\delta_1+\delta_2)$.

% これを使って書いたのがcode:\ref{stan::21_04}です。
I used this to write it: code:\ref{stan::21_04}.

Both methods return the same estimated results. Computing the difference from the generation amount of the first model is equivalent to computing $\delta_1$ and $\delta_2$.
