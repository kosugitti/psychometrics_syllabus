\subsection{Practical Application of the IRT Model}
% データの感じがわかったところで，IRTモデルを実行していきましょう。
Now that we understand the feel of the data, let's proceed with executing the IRT model.

% 今回は3つのモデルを試してみます。確認のために，少しモデル式に言及しておきます。困難度母数だけに注目するのが\keyterm{1パラメータ・ロジスティックモデル}{1ぱらめーたろじすてぃっくもでる}{1 parameter logistic model, 1PL}で，モデル式は次の通りです。
This time, we will try three models. For confirmation, let's mention a bit about the model equation. The \keyterm{1 parameter logistic model, 1PL} that focuses only on the difficulty parameter, and the model equation is as follows.

\[ p_j(\theta) = \frac{1}{1+exp(-1.7 (\theta -b_j))} \]

ここで$p_j(\theta)$は能力が$\theta$のひとが項目$j$に正答する確率であり，$b_j$が\keytermL{困難度母数}{こんなんどぼすう}{difficulty parameter}と呼ばれます。これは開発者の名前を使って，別名\keyterm{ラッシュモデル}{らっしゅもでる}{rasch model}とも呼ばれています。

項目の識別力にも注目するのが\keyterm{2パラメータ・ロジスティックモデル}{2ぱらめーたろじすてぃっくもでる}{2 parameter logistic model, 2PL}で，モデル式は次の通りです。

\[ p_j(\theta) = \frac{1}{1+exp(-1.7 a_j(\theta -b_j))} \]

% ここで$a_j$は\keyterm{識別力母数}{しきべつりょくぼすう}{descriminant paramter}と呼ばれます。
Here, $a_j$ is called the discriminant parameter.

% 最後に\keyterm{3パラメータ・ロジスティックモデル}{3ぱらめーたろじすてぃっくもでる}{3 parameter logistic model, 3PL}では，困難度，識別力に加えて\keyterm{当て推量母数}{あてすいりょうぼすう}{guessing parameter}というのを推定します。モデル式は次の通りです。
Finally, in the \keyterm{3 parameter logistic model, 3PL}{3ぱらめーたろじすてぃっくもでる}{3 parameter logistic model, 3PL}, in addition to difficulty and discriminatory power, a \keyterm{guessing parameter}{あてすいりょうぼすう}{guessing parameter} is estimated. The model formula is as follows.

\[ p_j(\theta) =c+ \frac{1-c}{1+exp(-1.7 a_j(\theta -b_j))} \]

もちろん式ではピンと来ないという人もいると思いますので，実際にどのように表されるかみていきましょう。

\section{段階反応モデルの実際}

続いて\keytermL{段階反応モデル}{だんかいはんのうもでる}の練習に進みましょう。項目反応理論は正答/誤答の二値データに対して用いるものでしたが，これを多段階反応に拡張したモデルの1つが段階反応モデルです。多段階反応とは，「まったく当てはまらない」を1，「非常に当てはまる」を7とする，といったような\keytermL{リッカート尺度}{りっかーとしゃくど}のようなスタイルの調査項目です。反応させるカテゴリの段階数に応じて，5件法とか7件法と呼ばれたりします。

リッカート尺度の場合は，シグマ法をつかって累積度数からカテゴリに該当する値を算出し，それを元に態度得点を作るという方法でした。とはいえこのやり方でやっても，いい尺度であればそのまま素点を尺度値としてもほとんど問題がないため，シグマ法が回りくどい方法だと思われたのか，使われなくなってしまいました。しかし実際には「いい尺度であれば」という条件を満たしているかどうか，しっかり確認しなければなりません。歪んだ分布や偏ったカテゴリ反応なのに，素点をそのまま尺度値とするのは不適切なことがあります。また，リッカート尺度で撮られたデータは因子分析をすることによって，解釈度に分類されて，因子ごとのスコアを算出して利用されることが一般的です。しかし，尺度値が適切でなければ，ピアソンの積率相関係数も適切ではなく，そこから計算が始まる因子分析のモデルにも疑義が生じます。

カテゴリ反応はあくまでも並びの問題であって，\keytermL{順序尺度水準}{じゅんじょしゃくどすいじゅん}の情報しか持たないと考えるのであれば，その背後にある態度のような連続体を仮定し，この態度$\theta$が大きくなることで徐々に反応カテゴリが変わる，という\keytermL{段階反応モデル}{だんかいはんのうもでる}のほうが適切な分析方法になるわけです。

項目反応理論(の段階反応モデル)を使って確認することは決して難しくありません。今回は因子分析の時に使った\texttt{bfi}データの一部を使って段階反応モデルを実践してみましょう。一部を使うとしたのは，段階反応モデルは項目反応理論の中間ですから，潜在変数が1次元(一因子)である，という仮定があるからです。ここでは\texttt{N}因子(Neuroticism，神経質さ)を使った例を示しています。

\begin{lstlisting}[language=c++,label={code:11_05},caption={GRMの実行}]
library(psych)
dat <- bfi %>%
  dplyr::select(-gender, -education, -age) %>%
  dplyr::select(starts_with("N"))
result.grm <- grm(dat)
result.grm
plot(result.grm, type = "ICC", items = 1)
plot(result.grm, type = "IIC", items = 1)
plot(result.grm, type = "ICC", items = 4)
plot(result.grm, type = "IIC", items = 4)
plot(result.grm, type = "IIC", items = 0)
\end{lstlisting}

\paragraph{コード解説}
\begin{description}
	\item[1行目] \texttt{psych}パッケージを読み込む。サンプルデータ\texttt{bfi}を用いるためです。
	\item[2-4行目] データの加工。\texttt{bfi}データから，性別，最終学歴，年齢などの情報を取り除き，またNで始まる変数だけ選出(\texttt{select})しています。
	\item[5行目] 段階反応モデルの実行。
	\item[6行目] 結果の出力。
	\item[7行目] 項目1についてのICC，厳密には\keyterm{項目反応カテゴリ特性曲線}{こうもくはんのうかてごりとくせいきょくせん}{Item Response Category Characteristic Curve}と呼びます。
	\item[8行目] 項目1についてのIICを表示させています。
	\item[9行目] 項目4についてのICCを表示させています。
	\item[10行目] 項目4についてのICCを表示させています。
	\item[11行目]項目群についてのTICを表示させています。
\end{description}

\texttt{code:\ref{code:11_05}}の6行目で，分析結果の数値的出力をさせていますので，それをみておきましょう(出力\ref{RS:out11_25})。

\section{カテゴリカル因子分析との対応}
さて多段階反応による分析も簡単にできることがわかりましたが，気になるのは段階反応モデルが一因子構造しか仮定していないところです。bfiデータはビッグファイブと呼ばれるように五因子(5次元)の仮定があるのですが，一因子ずつ\texttt{grm}を実行し，あとで統合するのは大変です。

でも大丈夫。簡単に多次元に展開する方法があります。
いわゆる一般的な因子分析は，ピアソンの積率相関係数を元に(積率相関係数の相関行列$\bm{R}$の固有値分解から)因子を求めていくのですが，この積率相関係数が\keytermL{間隔尺度水準}{かんかくしゃくどすいじゅん}を仮定したもので，シグマ法で計算された尺度値を使っていないのであれば疑義が残る，という話でした。
この元になる相関係数が，潜在的連続体を仮定した順序尺度水準向けの相関係数である，\keytermL{ポリコリック相関係数}{ぽりこりっくそうかんけいすう}であれば，その問題は解決します。反応段階が順序尺度を仮定した因子分析のことをとくに\keytermL{カテゴリカル因子分析}{かてごりかるいんしぶんせき}と言います。カテゴリカル因子部な席は，前回紹介した\texttt{psych}パッケージに少しオプションを足すだけで簡単に実行できるものです。

\begin{lstlisting}[language=c++,label={code:11_06},caption={GRMの実行}]
dat <- bfi %>% dplyr::select(-gender, -education, -age)
result.fa <- fa.poly(dat, nfactors = 5, rotate = "geominQ")
print(result.fa, sort = T, cut = 0.3)
\end{lstlisting}

\paragraph{コード解説}
\begin{description}
	\item[1行目] サンプルデータ\texttt{bfi}の加工をしています。
	\item[2行目] ポリ個リック相関係数に基づく因子分析の実行
	\item[3行目] 結果の出力。
\end{description}

コードの2行目を見ていただくとわかる通り，ただの\texttt{fa}関数ではなく\texttt{fa.poly}としただけで，あとは因子分析と同じです。この\texttt{.poly}のところがポリコリック相関係数を使うよう指定しているところで，これで実質的に測定尺度水準が順序尺度水準であると想定した因子分析をしたことになっています。

カテゴリカル因子分析は，段階反応モデルと数学的に等価であることが知られています。出自が違いますので，分析の数字や出力方法に違いがありますが\footnote{たとえば因子分析の文脈では，因子負荷量を提示して単純構造を目指すのに対し，項目反応理論の文脈ではIRCCCを描いたりTICを描いたりして各反応カテゴリの特徴を精査します。}，実質的には同じことをしていると理解してください。また，Rではたった数文字追加するだけで適切な分析方法になるのですから，使わない手はないと思います。

カテゴリカル因子分析は，因子分析の文脈から順序尺度水準の項目を扱えるように，と発展してきたものです，これに対して，項目反応理論の文脈から心理尺度を扱えるように，と発展してきたルートもあります。これは\keyterm{多次元項目反応理論}{たじげんこうもくはんのうりろん}{multi-dimensional item response theory}と呼ばれるもので，これを提供するRパッケージもあります。それが\texttt{mirt}パッケージ\citep{mirt}です。最後にこれを使ったコードの例を示しておきます。この計算には時間がかかりますが，完全情報最尤推定によって項目反応理論で算出するような，精度の高い\keytermL{因子得点}{いんしとくてん}を得ることができるのは利点だと言えるでしょう。

\begin{lstlisting}[language=c++,label={code:11_06b},caption={mirtの実行}]
library(mirt)
result.mirt <- mirt(dat, 5)
print(result.mirt)
result.mirt %>% summary(rotate = "geominQ")
\end{lstlisting}
