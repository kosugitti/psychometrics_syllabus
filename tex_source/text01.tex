% \item[数値化の利点] 近代科学の特徴である実験主義や機械論を取り入れたものが心理学であるならば，心理学において数量的表現が取り入れられることは当然である。しかし範とする物理学と違って，心理学の場合は研究対象が目に見えず測定する単位も持たない対象であるという特徴を持つ。その上で数量的アプローチをとる必然性を理解する。
\begin{flushright}
    $\to$\citet{三浦201705}のP.79--81.
\end{flushright}

% \item[数学的現象主義] ニュートンやガリレオが行なったのは，関数による数学的現象主義であり，心理学そのものは基本的にその枠組みの中に位置する。すなわちアウトカム変数に対して心というモデルを立てて，そのモデルの正しさを検証することが一つの目的である。アウトカム変数は数量化されていなくてもよいが，数量化されていた方が正確性，客観性，比較可能性，要約可能性に優れており，かつ統計モデルの活用により表面的に現れる数字から見えない情報を引き出すことが可能になっている。
