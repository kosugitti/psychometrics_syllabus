\section{ベイズモデリングへの入り口: Stanとそのフロントエンド}
\label{b29_bayesianModeling}

\subsection{授業内容}

\subsubsection{概要}
ベイズ的判断の方法を学んだあと，JASPでベイズ分析を体験した。しかしJASPのメニューにないモデルを扱いたくなったときには，確率的プログラミング言語による自前のモデリングが必要になる。本コマでは確率的プログラミング言語の代表であるStanを紹介し，そのRフロントエンドであるbrmsを用いれば従来の式記法から自動でStanコードが生成されることを学ぶ。これにより，Stanのコードを直接書かなくてもベイズモデリングを実用できることがわかる。また，確率的プログラミング言語のもとで初めて自由に設計できる生成量や事後予測分布についても扱う。最後に，brmsが出力するStanコードを読むことで，自分でモデルを書くための第一歩を踏み出す。本コマで扱うのは入口部分にとどめ，各種モデリングの具体的な応用や，心理学領域での発展的なモデリングについては3年次「ベイズ統計学」に委ねる。

\subsubsection{コマ主題細目}
\begin{description}
	\item[確率的プログラミング言語とは] Stanを代表とする確率的プログラミング言語（Probabilistic Programming Language; PPL）の登場により，複雑な確率モデルでも事後分布を数値的に近似できるようになった。本節ではまずなぜそのようなツールが必要なのか，MCMC法の基本的な仕組みを直観的に理解する。これまでベイズ推定の章で「裏で動いている計算」と呼んできたものの正体がここで明らかになる。

	\item[brmsによる実用的モデリング] Stanを直接書くのは敷居が高いが，Rのbrmsパッケージを使えば従来のlm()やglm()のような式記法でStanのモデルを書ける。R式から自動でStanコードとRデータが生成され，MCMCが走り，事後分布が返ってくる。brms::make\_stancode()を使えば自動生成されたStanコードを覗くこともでき，自分で書く際の参考にできる。具体例として線形回帰のベイズ版をbrmsで実装し，JASPで体験した分析と同じものをコードで再現する。

	\item[生成量と事後予測分布] 確率的プログラミング言語のもとでは，事後分布から好きな量を計算する「生成量」を自由に設計できる。例えば2群の平均値の差そのものや，ある群が別の群より大きくなる確率（優越率），観測値がどの程度の範囲に収まるか（被覆率）などである。事後予測分布を使った判断は，前々コマで添え物として触れたものを実装視点で拾い直すことになる。brmsのposterior\_predict()や生成量を使った具体例を学ぶ。

	\item[自分でStanコードを書くために] brmsから出力されたStanコードを読むことで，Stanの文法やデータブロック・パラメータブロック・モデルブロックの構造に親しむ。完全なゼロから書くのは難しいが，brmsの出力を編集する形で自分のモデルを作るアプローチが現実的である。各種モデリング（分散の検定，打ち切り・切断，混合分布，潜在クラス，階層モデルなど）の発展的な内容や，心理学領域での応用例は，3年次「ベイズ統計学」（半期）で扱われる。本コマはそこへの橋渡しと位置づける\footnote{なお，cmdstanrを直接使いたくない人向けにRTMBをベースとしたBayesRTMBのようなパッケージも登場しているが，その後Stanの書法を学び直すコストを考えると，本書では最初からbrms経由でStanに親しむ道を勧める。}。
\end{description}

\subsubsection{予習・復習課題}
\paragraph{予習}
JASPまでで学んだベイズ的判断の方法と，JASPの限界（メニューにないモデルは書けない）について確認しておくこと。特に前々コマで「添え物」扱いだった事後予測分布について，その考え方を再確認しておくと，本コマの生成量・事後予測分布節の理解がスムーズになる。Rとbrmsを各自の環境でインストールしておくと，授業中のデモがそのまま手元で動かせる。

\paragraph{復習}
授業で学んだ内容を定着させるために，以下の点について理解を深めておくこと：
\begin{enumerate}
  \item brmsがR式からStanコードを自動生成することを，make\_stancode()を使って確認できるようにする
  \item 自分が知っている統計分析（t検定，回帰，分散分析）をbrmsで書いてみる
  \item 生成量と事後予測分布が，JASPでは出力できない判断材料を提供することを説明できるようにする
  \item brmsが出力したStanコードを読み，データブロック・パラメータブロック・モデルブロックがどのように構成されているか確認する
  \item 3年次「ベイズ統計学」で扱われるであろう発展的なモデリング（分散の検定，打ち切り，混合分布など）について，どのような問題を解くものか興味のあるものを一つ調べてみる
\end{enumerate}
本コマで授業は終了であるが，ベイズモデリングの世界は半期ではとても語り尽くせない。3年次の授業に進むかどうかにかかわらず，この入口で得た見取り図を元に，自分のデータと向き合う際にベイズ的アプローチも選択肢に入れられるようにしておいてほしい。
