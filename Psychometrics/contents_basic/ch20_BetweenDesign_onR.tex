\chapter{Rによる分散分析}
\label{ch20_BetweenDesign_onR}

前回まで，要因計画＋統計的判断＝分散分析として，その理論的背景と計算方法について学んできました。またRを使った実習では，\verb|lm()|関数と\verb|aov()|関数を使って，分散分析を実行する方法についても学びました。下位検定を行う際も，\verb|TukeyHSD()|関数や\verb|effectsize|パッケージを使って，効果量を計算する方法についても学びました。今回の講では，Rで分散分析を行う際に便利な\verb|anovakun|関数を導入し，その使い方について学びます。\verb|anovakun|は，分散分析の主な分析から事後検定までを一括して実行できる便利な関数です。これにより，分散分析の手順が簡略化され，より効率的に分析を行うことができます。

\verb|anovakun|関数を使うことで，一要因群間計画だけでなく，二要因群間計画の分散分析も簡単に実行できます。それどころか，三要因以上の複雑な要因計画にも対応しています(実に26要因計画まで分析可能です。もちろんそんな複雑な計画は立てない方がいいです。)。またこの関数の便利なところは，分散分析表や効果量の出力だけでなく，下位検定まで自動的に行ってくれるところです。

\section{分散分析用の関数の導入}

今回導入するのは，\verb|anovakun|という関数です\footnote{かつて，下位検定まで自動的にやってくれる統計パッケージはありませんでした。広島大学ご出身の桐木建始先生が，4要因まで分析可能なプログラムを書き，そのコードが広島大学大学院での秘伝ソースとして共有されていました。その後，非常に便利なそのプログラムがWebでも実行できるANOVA4 on the webとしてネットで公開され，当時(2000年頃)大学院生だった筆者を始め，多くの研究者はそれを使って分散分析をしていました。その後，井関龍太先生がRでANOVA4のような，下位検定まで一気に計算してくれるプログラムを，ということでanovakunを開発され，現在まで公開されているという歴史があります。有料化されたサービスにすることもできたでしょうが，計算手続きがオープンソースで，フリーソフトウェアとして無償で公開されることはとても有意義な文化だと思いませんか。}。これはネットで一般に公開されています\footnote{\url{https://riseki.cloudfree.jp/?ANOVA君}}。CRANからダウンロードするパッケージのようにはなっていませんので，これを使うにはローカルに\texttt{anovakun}関数を書いたファイル(執筆時点，2025年10月現在で\verb|anovakun_489.txt|)をダウンロードし読み込むか，Rから直接インターネット経由でダウンロードして使うか，の2通りの方法のいずれかを使う必要があります。どちらにしても，Rの\texttt{source}関数をつかうもので，ダウンロードしたファイルを使う場合は\underline{プロジェクトフォルダに当該ファイルをダウンロードした上で}，読み込むコードを実行します(\texttt{code:\ref{code:20_01}})。

\subsection{anovakun関数の使い方}
まずは前回やった，一要因3水準の分散分析を\verb|anovakun|関数を使ってやってみましょう。データは前回と同じです。
データの作り方は\texttt{code:\ref{code:19_03}}の通りです。これを使って\verb|anovakun|関数を実行するには，次のようにします(\texttt{code:\ref{code:20_03}})。


\begin{lstlisting}[language=c++,label={code:20_03},caption={一要因3水準の分散分析をanovakunで実行}]
# データフレームを組み上げる
Example1 <- data.frame(id = 1:12,
                       condition = rep(1:3,each=4),
                       value = c(6,6,5,5,7,4,7,6,4,3,4,6))
# 要因型にする
Example1$condition <- factor(Example1$condition,
                             labels = c("control","exp1","exp2"))

# anovakun関数で分散分析を実行
anovakun(Example1[, -1], "As", 3, eps = TRUE)
\end{lstlisting}

\paragraph{コード解説}
\begin{description}
	\item[1-7行目] 前回と同じなので省略します。
	\item[10行目] \verb|anovakun|関数を実行しています。引数は，データ，要因計画の型，要因の水準数，効果量を表示するかどうか，です。
\end{description}

\verb|anovakun|関数の使い方のポイントは，要因計画の型を文字列で指定するところです。詳しくは開発者である井関先生のサイト\footnote{\url{https://riseki.cloudfree.jp/?ANOVA君/ANOVA君の使い方}}を参照してもらいたいのですが，基本的な使い方は次の通りです。

\verb|anovakun(データ, "要因計画の型", 各要因の水準数，...)|

まずデータです。ここでは\verb|Example1[,-1]|としています。\verb|Example1|はデータフレームで，ID，水準，値が入っているわけですが，\verb|anovakun|に渡すでーたはIDが必要ありません。そこで1列目を除外して渡します。除外の方法として，ここでは\verb|Example1[,-1]|としています。これは，\verb|Example1|の1列目を除外して，残りの列を返す，という意味です。データフレームオブジェクトには，\verb|[行,列]|という形で要素が指定できること，マイナスの記号で削除できることなどから，列の部分に\verb|-1|とすることで，1列目を除外して残りの列だけをとりだす，ということにしています。実際に，Rの画面で\verb|Example1[, -1]|を実行すると，\verb|Example1|の1列目を除外したデータが表示されますので，確認してみてください。あるいは，\verb|tidyverse|に含まれる\verb|dplyr|を使って，\verb|Example1 %>% select(-id)|のようにしてもいいでしょう。

さて，ともかくこれでデータは渡せたわけですが，ここからが本番です。次に，このデータがどういう要因計画のものなのかを示す必要があります。今回は\verb|"As"|と書いていますね。ここで小文字のsは実験参加者を表していて，sの左側にあるのは群間要因，sの右側にあるのは群内要因を表しています。要因にはA,B,C,...,Z でラベルをつけます。今回は一要因(要因はAだけ)で，群間要因なので\verb|"As"|とします。もし群内要因であれば\verb|"sA"|とします。この指定の仕方，表\ref{tbl:20_01}にまとめておきますので，参考にしてください。

\section{データの作りかた}
\label{MakingData}
ということで，この関数を使うといろいろな分析ができます。これから2要因Betweenの例を見ていくのですが，その前にデータの作り方について少し解説しておきます。
\subsection{整然データ}
一般に心理学で作るデータセット，データファイルは，1セルに1情報，重複や集計，オブジェクトや文字列のないデータセットであることが基本です。
また図\ref{fig:app_gooddata_02}にあるように，一行ごとに1人(1ケース，1オブザベーション，1レコードとも言います)のデータが入っており，各列が変数を表すようにすることが一般的です。変数が増えると横に伸びていきますので，こうしたデータの入力形式を\keytermRL{ワイド型}{わいどがた}のデータということがあります。

ここで表\ref{tbl:20_02}を見てください。このデータを見ると我々は，「大阪の午後は曇りなんだな」ということがすぐにわかります。

しかしその判断は，「大阪」行の「午後」列を見て，すなわち行と列に素早く目を走らせてそれのクロスするところで「曇」という情報を得ています。夕方や深夜の情報が知りたければ，列を変えますね。列ごとに違う変数になっているから当然です。行と列の名前を参照するというのは，目線を左右と上下に動かす2アクション必要なことです。

しかしここで参照している「列名(変数名)」も変数，データの一部ではないでしょうか。この観点に立ち，1行見るだけですべての情報がわかるようにしてみましょう。表\ref{tbl:20_03}には表\ref{tbl:20_02}と同じ情報しか含まれていませんが，一行見るだけですべての情報がわかるようになっています。

表\ref{tbl:20_03}のような形のデータのことを，\keytermRL{ロング型}{ろんぐがた}のデータと言います。
このような形にしておくと，情報の欠落(欠測値)があった時の対応が楽に行えたり，レコードの選択がやりやすくなるなどの利点があります。

このような分析しやすいデータの形について，\textcite{Hadley2014}が提唱したのが\keytermR{整然データ}{せいぜんでーた}{tidy data}という考え方です。整然データとは，次の4つの特徴を持ったデータ形式のことです。
\begin{itemize}
	\item 個々の変数(variable)が1つの列(column)をなす。
	\item 個々の観測(observation)が1つの行(row)をなす。
	\item 個々の観測の構成単位の類型(type of observational unit)が1つの表 (table) をなす。
	\item 個々の値 (value) が1つのセル (cell) をなす。
\end{itemize}
さきほどの天気の例では，時間，場所，天候という3つの情報が表に含まれていますが，これが一行の中にまとまっているのが整然データです。
人間にとってはワイド型のデータの方がわかりやすいこともありますが，分析を進めていく上ではロング型・整然データの方が便利なことも多くあります。たとえばこの後で行う作図においては，整然データの方が便利な形です。X軸に割り当てる列，Y軸に割り当てる列，色や形を指定する列，など列ごとに持つ特徴を図の設定に割り当てることができるからです。

実際にデータを入力するときは，人間にとってわかりやすいワイド型が便利ですが，統計的な処理をしたり，グラフを描画するときにはロング型の整然データの方が便利です。そこで，ワイド型のデータをロング型の整然データに変換する方法を学びましょう。ありがたいことに，\verb|tidyverse|というパッケージを用いると，こうしたデータの加工が非常に楽に行える関数をいろいろ使うことができます。

\subsection{分散分析のデータ形式}

では実際に分散分析を行う際は，どのようなデータ形式にすればよいのでしょうか。\verb|anovakun|はロング型にもワイド型にも対応していますが，まずはワイド型で入力する方がわかりやすいでしょう。すなわち，各列が変数を表し，各行が1人(1ケース)のデータを表す形です。

群内要因のデータを列(横)に並べ，群間要因のデータを行(縦)に並べるのが基本です。次の例は，2要因の混合計画(間(3)$\times$内(2))のデータ例です。

\begin{lstlisting}[language=c++,label={code:20_04},caption={データの準備}]
library(tidyverse)
MixedDesign <- data.frame(id = 1:12,
                       condition = rep(1:3,each=4),
                       stimuli1 = c(6,6,5,5,7,4,7,6,4,3,4,6),
                       stimuli2 = c(8,3,2,5,9,7,1,6,4,9,2,3))
# 要因型にする
MixedDesign$condition <- factor(MixedDesign$condition,
                             labels = c("control","exp1","exp2"))
print(MixedDesign)
\end{lstlisting}
\paragraph{コード解説}
\begin{description}
    \item[1行目] \verb|tidyverse|パッケージを読み込んでいます。
    \item[2-5行目] データフレームを作成しています。被験者ID，条件変数，刺激1，刺激2の4つの変数があります。
    \item[6-8行目] 条件変数を要因型にしています。ラベルは統制群(control)と実験群1(exp1)，実験群2(exp2)としています。
    \item[9行目] データフレームを表示させています。
\end{description}

さてここで，\verb|tidyverse|パッケージを使うとワイド型とロング型を相互に変換できることを説明しておきます。ワイド型のデータをロング型に変換するには，\verb|pivot_longer()|関数を使います(\texttt{code:\ref{code:20_05}})。

\begin{lstlisting}[language=c++,label={code:20_05},caption={ワイド型からロング型への変換}]
MixedDesign_long <- MixedDesign %>%
  pivot_longer(cols = c(stimuli1,stimuli2),
               names_to = "stimuli",
               values_to = "value")
print(MixedDesign_long)
\end{lstlisting}

\paragraph{コード解説}
\begin{description}
    \item[1行目] ワイド型のデータフレームをロング型に変換し，新しいデータフレーム\texttt{MixedDesign\_long}に代入しています。
    \item[2-4行目] \verb|pivot_longer()|関数を使って，\texttt{stimuli1}と\texttt{stimuli2}の列をロング型に変換しています。変換後の変数名は\texttt{stimuli}，値の入る変数名は\texttt{value}としています。
    \item[5行目] 変換後のデータフレームを表示させています。
\end{description}

最初に，水準ごとの平均値と標準偏差が表示され，続いて分散分析表が示されています。ご丁寧に有意かどうかわかりやすいような記号(\verb|.|や\verb|*|など)がついています。最後の一行には\texttt{+p < .10, *p < .05, **p < .01, ***p < .001}とありますが，これは米印が1つなら5\%，2つなら1\%，3つなら0.1\%水準で有意である，という意味です。さらに，\verb|+|の記号であれば10\%水準で有意であるということもわかります\footnote{おそらくこれが諸悪の根源で，なんとなく星の数が多い方が「良い結果」のような印象を持ちますし，分析したらとりあえず星を探す，という仕草が生まれるようになっていますよね。帰無仮説検定はあくまでもモデル比較の判定であって，判定基準が厳しいほど「良い」とか，基準をクリアできなかったから「惜しい(残念)」という評価を伴うものではないはずなのに，です。有意差がなかったら，そういう結果が得られた，というだけですし，星の数が小さくてもえらいとかすごい，ということにはならない，ということを再確認してください。「心理学者は星を探して喜んでるんだ」というようなジョークの的にならないように，適切な分析的素養を身に付けましょう。}。これを見ると，要因A(温度)の主効果はなく($F(1,8)=0.500,p=0.4996$)\footnote{米印があるべきところに$ns$とありますが，これはnot significant，つまり有意ではないという意味です。}，ついで要因Bの効果も5\%水準では認められない(10\%水準で有意，その記号として$+$が使われています)\footnote{世の中には「有意傾向」という変な言葉があります。今回要因Bの$p$値は6\%でしたが，これは5\%水準ではアウトですよね。こういった5\%をちょっとだけ上回っちゃった，惜しい！というときに，「有意になりそうな傾向があった」略して「有意傾向があった」という表現がされることがあるのです。あるいは「傾向差があった」という言葉もまことしやかに使われていたりします。が，これらは心理学独自の間違った表現であり，決して使うべきではありません。なぜなら，5\%だろうが6\%だろうが，任意に決めた判定基準であって，$p$ 値の大小関係は現実の効果の大きさとは関係がないからです。}，また交互作用は5\%水準で有意という結果になりました。さらに効果量$\varepsilon^2$の列を見ると，交互作用は全体の62\%の分散を説明したことになりますから，これはかなり大きな効果だったようだ，ということがわかります。

まず記述統計量(DESCRIPTIVE STATISTICS)，これは意味がわかるでしょう。
次に分散分析表(<< ANOVA TABLE >>)で，これがメインの出力です。今回は要因A，要因Bともに有意，さらに交互作用も有意です。全部の効果が有意だということがわかりました。これを順番に読み解いていきます。

\paragraph{要因Aの主効果}まずは要因Aの主効果です。これは2水準なので，以後の検定は必要ありません。要因Aの水準1と水準2の平均値を比較して，どちらが大きいかを見ればよいです。平均値は記述統計量の表に出ていますが，計算して要因Aの周辺平均にしなければなりません。つまり，水準1は

\[ (5 \times 42.2 + 5 \times 52.8 + 5 \times 32.2) / (5 + 5 + 5) = 42.4 \]
で，水準2は
\[ (5 \times 39.8 + 5 \times 54.6 + 5 \times 57.2) / (5 + 5 + 5) = 50.5333 \]
となります。$42.4 < 50.5333$ですから，水準2の方が大きい，ということになりますね。今回は各セルのサンプルサイズが同じだったので3つの平均でも良かった(全部5でくくって，5で割るだけですから)のですが，，もしサンプルサイズが違う場合は，丁寧に周辺平均を計算する必要があります。
ちなみにこの計算は，\verb|anovakun|の出力には含まれません。「2水準で差があるんだから，わかるだろ」ということです。自分で計算するんですよー。

\paragraph{要因Bの主効果}ここは3水準なので，どこに差があるかわかりません。ということで，下位検定の対象になります。\verb|<< POST ANALYSES >>|のセクションは，この要因Bの主効果を細かく見ていくところから始まります。まず\verb|< MULTIPLE COMPARISON for "B" >|とありますが，これが「要因Bの下位検定をやるよ」という意味です。「Bの多重比較」というセクションですね。ここでは，Shafferの方法で多重比較をしています。5\%水準でやるよ，と宣言もされています。

ここではまずBの各水準についての記述統計，周辺平均が計算されています。その上で，一要因3水準の検定のときのように，どこの水準とどこの水準の間に差があったのかを見ています。結果を見ると，b1-b2の差は有意，b2-b3の差も有意，b1-b3の差は有意ではない，ということがわかります。つまり，b1とb2の間に差があり，b2とb3の間にも差があるけれども，b1とb3の間には差がない，ということです。

左の図\ref{fig:20_02}にあるように，まずはbの各水準においてAが効果を及ぼしているかどうかを見ます。\verb|anovakun|の出力で，\verb|A at b1|はb1水準におけるAの効果を，\verb|A at b2|はb2水準におけるAの効果を，\verb|A at b3|はb3水準におけるAの効果を見ています。結果を見ると，b1とb2では有意ではないですが，b3では有意な差が出ています。つまり，b3の水準においては，a1とa2の間に差がある，ということです。ここでAは2水準なので，差があればそのままその差がどちらの水準の方が大きいかを見ればよいです。冒頭の記述統計のところに戻ると，\verb|a1 b3|が32.2，\verb|a2 b3|が57.2ですから，a2の方が大きい，ということになります。

次は右の図\ref{fig:20_03}にあるように，Aの各水準においてBが効果を及ぼしているかどうかを見ます。出力の方から，とりあえず，\verb|B at a1|，\verb|B at a2|がいずれも有意であることがわかりました。厄介なことに，ここでBは3水準ですから，効果があったとしてもどこに効果があったかまではわかりません。3水準のときは，さらに下位検定を行う必要があります。ここでは，\verb|< MULTIPLE COMPARISON for "B at a1" >|と\verb|< MULTIPLE COMPARISON for "B at a2" >|のセクションで，それぞれの水準におけるBの下位検定を行っています。結果を見ると，a1水準ではb2(52.8)がb3(32.2)よりも大きく，b1(42.2)がb2(52.8)よりも小さく，b1(42.2)とb3(32.2)の間にも有意な差がある，ということがわかります。つまり，a1水準では$b2 > b1 > b3$という順序になります。またa2水準ではb1がb3よりも小さく，b1がb2よりも小さいのですが，b2とb3の間は有意ではない，ということがわかります。$b2,b3 > b1$という関係ですね。

以上ですべての関係・結果がわかりました。基本的には同じような操作を繰り返していくわけです。どこにフォーカスしているか，ということをしっかり意識しながら結果を読んでいかないと，訳がわからないことになりますね。出力を見ながら，図を見ながら，どの部分を見ているのかを意識して読み解いていくことが大切です。

\section{分析結果の可視化}
さて，最後の例はなんだかわかりにくい結果でした。が，これは数字で見ているからそうなのであって，図にしてみると多少その複雑さが和らぎます。百聞は一見にしかず，です。これらの結果を見やすくするために，図\ref{fig:20_04}に可視化してみました。
\begin{figure}[ht]
	\centering
	\caption{分散分析結果の可視化1；棒グラフで平均値と標準誤差を表示}
	\label{fig:20_04}
	\includegraphics[keepaspectratio,width=0.8\linewidth]{figures/20_anovakun/anova_barplot.png}
\end{figure}

いかがでしょうか。こうすると群の平均がどのように違うのか，交互作用があるのかどうかが一目でわかります。加えて，平均値の標準誤差をエラーバーとして表示しているので，群間の差がどの程度のばらつきの中で生じているのかもわかります。

この図を書いたのは次のコードによるものです。コードの書き方は参考程度で結構ですが\footnote{このコードは生成AIのひとつ，Claude(Sonnet4.5モデル)に「分散分析の結果をggplot2で可視化するコードをかけ」と指示して書かせたものです。このように生成AIを使うとRのコードも書いてくれますのでコード自体を恐れる必要はありません。人間に必要なのは適切な指示を出すこと，ゴールのビジョンを明確に持つことです。}，どのようにして可視化できるかを確認してください(\texttt{code:\ref{code:20_09}})。

\begin{lstlisting}[language=c++,label={code:20_09},caption={可視化のコード}]
Between23 %>%
  group_by(A, B) %>%
  summarise(
    mean = mean(value),
    sd = sd(value),
    n = n(),
    se = sd / sqrt(n),
    .groups = "drop"
  ) %>%
  ggplot(aes(x = B, y = mean, fill = A)) +
  geom_bar(
    stat = "identity",
    position = position_dodge(0.9),
    width = 0.8
  ) +
  geom_errorbar(aes(ymin = mean - se, ymax = mean + se),
    position = position_dodge(0.9), width = 0.25
  ) +
  labs(
    title = "要因Aと要因Bによる平均値の比較",
    x = "要因B",
    y = "平均値",
    fill = "要因A"
  ) +
  theme_bw()
\end{lstlisting}

\paragraph{コード解説}
\begin{description}
	\item[1行目] データフレーム\texttt{Between23}をパイプ演算子\verb|%>%|で次の処理に渡しています。
	\item[2行目] \verb|group_by()|関数で，要因Aと要因Bの組み合わせごと(6つのセルごと)にデータをまとめています。
	\item[3-9行目] \verb|summarise()|関数で，セルごとの要約統計量を計算しています。平均値(\texttt{mean})，標準偏差(\texttt{sd})，データの数(\texttt{n})を求め，そこから標準誤差(\texttt{se})を標準偏差$/\sqrt{n}$で計算しています。\verb|.groups = "drop"|は，計算が終わったらグループ化を解除するという指定です。
	\item[10行目] \verb|ggplot()|関数で描画を始めています。\verb|aes()|の中で，横軸(\texttt{x})に要因B，縦軸(\texttt{y})に平均値，塗りつぶしの色(\texttt{fill})に要因Aを割り当てています。
	\item[11-15行目] \verb|geom_bar()|関数で棒グラフを描いています。\verb|stat = "identity"|は，データの値(ここでは平均値)をそのまま棒の高さにするという指定です。\verb|position_dodge(0.9)|で要因Aの2本の棒を重ねずに横に並べ，\verb|width|で棒の幅を決めています。
	\item[16-18行目] \verb|geom_errorbar()|関数でエラーバーを描いています。下端(\texttt{ymin})を平均値$-$標準誤差，上端(\texttt{ymax})を平均値$+$標準誤差にしています。棒と同じ\verb|position_dodge(0.9)|を指定しないと，エラーバーが棒からずれてしまいます。\verb|width|はエラーバーの横線の幅です。
	\item[19-24行目] \verb|labs()|関数で，図のタイトル，横軸と縦軸の名前，凡例の見出しを付けています。
	\item[25行目] \verb|theme_bw()|関数で，背景を白にした見た目(テーマ)にしています。
\end{description}

単純に，ボックスプロット(箱ひげ図)で表現するのもいいかもしれませんね。好みの問題ですけど。ボックスプロットで表示する例を図\ref{fig:20_05}に示します。

\begin{figure}[ht]
	\centering
	\caption{分散分析結果の可視化2；ボックスプロットで分布を表示}
	\label{fig:20_05}
	\includegraphics[keepaspectratio,width=0.8\linewidth]{figures/20_anovakun/anova_boxplot.png}

ボックスプロットは平均値に加え，データの分布や外れ値を視覚的に確認するのに便利です。また，今回は点ですべてのデータを重ねて表示しているので，どのような分布になっているのかもわかります\footnote{点をそのまま書くと，同じ値が重複して表示され見た目に違いがわからなくなりますので，左右に少し散らばるように書きました。この散らばらせるやり方をジッター(jitter)といいます。}。コードは次の通りです。

\begin{lstlisting}[language=c++,label={code:20_10},caption={箱ひげ図のコード}]
Between23 %>%
  ggplot(aes(x = B, y = value, fill = A)) +
  geom_boxplot(alpha = 0.5, outlier.shape = NA) +
  geom_jitter(aes(color = A),
    position = position_jitterdodge(jitter.width = 0.2),
    size = 2
  ) +
  labs(
    title = "要因Aと要因Bによる測定値の分布",
    x = "要因B",
    y = "測定値",
    fill = "要因A",
    color = "要因A"
  ) +
  theme_bw()
\end{lstlisting}
\paragraph{コード解説}
\begin{description}
	\item[1行目] データフレーム\texttt{Between23}を次の処理に渡しています。箱ひげ図は個々のデータから描くので，棒グラフのときのように平均値を先に計算する必要はありません。
	\item[2行目] \verb|ggplot()|関数で描画を始めています。横軸に要因B，縦軸に測定値(\texttt{value})そのもの，塗りつぶしの色に要因Aを割り当てています。
	\item[3行目] \verb|geom_boxplot()|関数で箱ひげ図を描いています。\verb|alpha = 0.5|で箱を半透明にして，重ねた点が見えるようにしています。\verb|outlier.shape = NA|は外れ値の点を描かないという指定です。次の行ですべてのデータを点で描くので，外れ値が二重に描かれるのを防いでいます。
	\item[4-7行目] \verb|geom_jitter()|関数で，個々のデータを点で重ねています。\verb|aes(color = A)|で点の色を要因Aで塗り分けています。\verb|position_jitterdodge()|は，要因Aの箱を横に並べる(dodge)のと，点を左右に少し散らす(jitter)のを同時に行う指定で，\verb|jitter.width|が散らす幅です。\verb|size|は点の大きさです。
	\item[8-14行目] \verb|labs()|関数で，タイトル，軸の名前，凡例の見出しを付けています。箱の塗りつぶし(\texttt{fill})と点の色(\texttt{color})の両方に要因Aを割り当てているので，両方に同じ見出しを付けて凡例を1つにまとめています。
	\item[15行目] \verb|theme_bw()|関数で，背景を白にしています。
\end{description}

\section{課題}

この講の課題は，伴走サイトの「各章のコード」にある\texttt{20\_kadai.R}を使って行います。このファイルには，ANOVA君を読み込むコード，課題のデータを作るコード，結果を図にするコードがすべて書いてあります。データを自分で入力する必要はありません。\texttt{anovakun\_489.txt}と一緒にプロジェクトフォルダに置いて，上から順に実行してください。自分で書くのは，「ここに書く」とある2か所の\verb|anovakun|関数の1行だけです。

\subsection{課題1：一要因3水準の群間計画}
ある研究者が，3つの記憶方略(反復・イメージ・精緻化)が記憶成績に与える影響を調べるため，各方略に6名ずつ，計18名の参加者を無作為に割り当て，記憶テストの得点を測定しました。データは\texttt{20\_kadai.R}の中で\texttt{kadai1}というデータフレームとして作られます。

\begin{enumerate}
	\item \texttt{kadai1}を\verb|anovakun|関数で分析するコードを書き，実行してください。効果量$\varepsilon^2$も出力すること。\texttt{id}の列は渡さないように注意してください(\texttt{code:\ref{code:20_03}}を参考に)。
	\item 記憶方略の主効果は統計的に有意でしょうか。分散分析表から$F$値，自由度，$p$値，効果量$\varepsilon^2$を読み取ってください。
	\item 主効果が有意であった場合，多重比較の結果から，どの方略とどの方略の間に差があるといえるかを答えてください。
\end{enumerate}

\subsection{課題2：二要因の群間計画}
ある研究者が，学習方法(対面・オンライン・ハイブリッド)と復習の有無(なし・あり)が学習成果に与える影響を調べるため，$3 \times 2$の6条件に5名ずつ，計30名の参加者を無作為に割り当て，学習後のテストの得点を測定しました。データは\texttt{20\_kadai.R}の中で\texttt{kadai2}というデータフレームとして作られます。

\begin{enumerate}
	\item \texttt{kadai2}を\verb|anovakun|関数で分析するコードを書き，実行してください。効果量$\varepsilon^2$も出力すること。要因計画の型と，各要因の水準の数を，どの順番で書けばよいかに注意してください(表\ref{tbl:20_01}を参考に)。
	\item 学習方法の主効果，復習の主効果，交互作用のそれぞれについて，統計的に有意かどうかを答えてください。また，効果量$\varepsilon^2$が最も大きいのはどれでしょうか。
	\item 交互作用が有意であった場合，単純効果の検定の結果を読み取ってください。たとえば\verb|B at a2|は何を検定したもので，結果はどうだったでしょうか。また，3水準の要因について多重比較が行われている場合，どの水準とどの水準の間に差があるといえるでしょうか。
	\item \texttt{20\_kadai.R}の後半にある3つの図のコードを実行し，図と分散分析の結果を見比べてください。交互作用プロットで，復習の効果(2本の線の開き)が最も大きいのはどの学習方法でしょうか。
